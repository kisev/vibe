## New

- 🤖 **Model catalog** — Settings → Models shows a bundled catalog of every ASR model the bundled engine can load (the handy layer plus vibe builds). Filter by streaming, translation, language, or provider; pick a quantization with its size shown; download with one click, every file verified against its published size and SHA-256. Installed models stand out in the list with select, rename, and delete right on the card, and every card links to its Hugging Face page
- 🧠 **One engine for every family** — the GGML runtime is now transcribe.cpp 0.4.1, loading Parakeet, GigaAM, Nemotron, Voxtral, Qwen and Canary alike. Whisper-only controls appear only for Whisper; streaming and translation follow what the loaded model actually supports
- 🧪 **Model comparison lab** — Settings → Models can record a short clip or pick an audio or video file, run two or more installed models over it one after another, and save each transcript as a Markdown report in a timestamped comparisons folder. Every run reports its wall-clock time; a failed run shows its reason and the remaining models still run. The borrowed accuracy and speed bars come off the catalog cards — quality is now judged on your own audio
- 🎙️ **Recording devices survive replugs** — selections match devices by name, so unplugging and replugging keeps your mic; while a pinned device is away it stays visible as unavailable and recording is refused with the device named instead of quietly using another. Hidden devices stay hidden and return when picked from the Hidden devices section of the microphone or speaker list
- ⏱️ **Long recordings plan themselves** — every bounded engine plans its speech ranges up front; an out-of-memory chunk is halved and that split is remembered, so a resumed run retries only the leaves that failed; finished chunks are cached, so re-running the same file with the same settings reuses them. The cache is automatic in the app (entries untouched for 30 days are cleared) and opt-in on the command line with `--cache-dir`. Speaker labels carry into every chunk, and lines where two turns meet show both speakers
- ✂️ **Chunk length is a setting** — Settings → Tuning gains a chunk-length field for models with an input limit, clamped to what the engine accepts (25 s for GigaAM, 30 s for Parakeet and Nemotron). Long recordings are split for every bounded engine; Whisper keeps its own long-form handling
- 📄 **Generated model docs** — the model list on the Models documentation page is generated from the catalog, so the models, their sizes, and their download links stay in step with what the app offers; a parity test keeps every catalog file pinned to a working link

## Improved

- 🗣️ **Better speaker labels** — speaker detection now runs NVIDIA Nemotron-3-Diarization instead of Sortformer, recognizing up to eight speakers instead of four. Existing installs are offered the new model once at startup, the superseded files are cleaned up, and declining turns speaker recognition off with a notice
- ⚡ **GPU acceleration restored** — Vulkan is back in the Windows and Linux builds and Metal in the macOS build, so the unified engine uses the GPU again; without a usable driver it runs on CPU as before, and a failed GPU load still falls back to CPU
- 🪟 **Settings open full-window** — the app window maximizes while settings is open and the sheet fills it, with room for the catalog and its filters; closing settings restores your window size
- ⬇️ **Downloads you can read** — while one download runs, the progress toast names its file; with several, it shows how many are running and the latest file's percentage. A finished catalog download flips its card to installed right away, and progress updates refresh only the toast, so the catalog stays responsive while a model downloads
- 🗑️ **Delete models from settings** — remove a downloaded model, including the one in use, or a single quantization without opening the folder
- 🏷️ **Vibe picks sit under Vibe** — the twelve Whisper GGUF builds the app offers now show under the Vibe provider in the catalog and its filter, while their downloads still resolve against the same files, sizes, and checksums
- 🪟 **Winget keeps the fork** — the Windows installer registers as its own apps-and-features entry (`vibe-kisev-fork`), so `winget upgrade` no longer replaces a fork install with the upstream package
- 🐧 **Arch Linux installs** — the Linux installer installs `vibe-bin` from the AUR with `paru` or `yay`, and builds it with `makepkg` when no AUR helper is present
- ⏺️ **The button says Record** — the main record button now names only the recording action instead of promising transcription it does not always run
- 🎙️ **Shortcuts use your microphone** — the dictation hotkey and recording shortcut record from the microphone selected on the home page instead of the system default
- 🌍 **Everything translated** — the catalog interface and the new settings strings are translated into all 21 non-English app languages, and the generated models docs into the 14 non-English languages the website supports
- 🔁 **Fork updates** — in-app updates check this fork's updater channel and release notes open this fork's changelog, and dev builds are cut on demand from `dev.*` tags instead of every commit

## Fixed

- 👁️ **The hide-devices eye button** no longer goes dead when the device picker is open — it hides the device without selecting it
- 💥 **Opening the device picker with hidden devices no longer crashes** — the hidden-devices group renders correctly
- 📉 **Parallel downloads stay separate** — each download's progress is tracked on its own, so one download no longer overwrites another's percentage; the toast shows the latest file's real percentage and how many downloads are running
- 🛡️ **Downloads survive an antivirus scan** — when Windows antivirus holds the finished file, the app retries for about a minute and a half instead of failing; a nearly finished download is kept across restarts and published on the next attempt without downloading again
- 🎥 **Google Meet detected on Windows** — meeting detection now remembers every browser process instead of only the first, so it finds the Meet window while a browser runs several processes
- ⏹️ **A second Stop no longer crashes** — pressing stop again while a recording is finishing is ignored instead of aborting the app
- 🗣️ **Speaker changes split the line** — a line that switches speaker mid-sentence is now split where the speaker changes, each part carrying its own speaker label. Chunked recordings also report real timestamps again instead of starting each chunk at zero
- 🕒 **Stable timestamps no longer break a recording** — a request that asks for stable timestamps on a model that cannot use them now drops the option instead of failing the transcription, so GigaAM recordings no longer error out with the preference left on
- 🌐 **Changelog no longer flashes English** — a translated changelog waits for its translation instead of painting English first and reflowing a moment later
