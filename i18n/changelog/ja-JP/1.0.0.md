## New

- 🤖 **モデルカタログ** — 設定 → モデル には、同梱エンジンが読み込めるすべてのASRモデル（handyレイヤーとvibeビルド）のカタログが同梱されています。ストリーミング、翻訳、言語、プロバイダーで絞り込み、サイズが表示された量子化を選び、ワンクリックでダウンロードできます。各ファイルは公開されているサイズとSHA-256で検証されます。インストール済みのモデルはリスト内で目立ち、カード上で選択、名前変更、削除ができ、各カードはHugging Faceのページにリンクしています
- 🧠 **すべてのファミリーを1つのエンジンで** — GGMLランタイムは transcribe.cpp 0.4.1 になり、Parakeet、GigaAM、Nemotron、Voxtral、Qwen、Canaryを同様に読み込めます。Whisper専用のコントロールはWhisperのときだけ表示され、ストリーミングと翻訳は読み込んだモデルが実際に対応している内容に従います
- 🧪 **モデル比較ラボ** — 設定 → モデル では、短いクリップを録音するか音声・動画ファイルを選び、インストール済みの2つ以上のモデルで順番に実行し、各文字起こしをタイムスタンプ付きの比較フォルダにMarkdownレポートとして保存できます。各実行は実時間を報告し、失敗した実行は理由を表示したうえで残りのモデルも引き続き実行されます。借用していた精度と速度のバーはカタログのカードから外れました — 品質は自分の音声で判断するようになりました
- 🎙️ **録音デバイスは抜き差ししても維持** — 選択はデバイス名で照合されるため、抜き差ししてもマイクは維持されます。固定したデバイスが外れている間は「利用不可」として表示され、別のデバイスを黙って使う代わりに、デバイス名を示して録音が拒否されます。非表示のデバイスは非表示のまま残り、マイクまたはスピーカーのリストの「非表示のデバイス」セクションから選ぶと元に戻ります
- ⏱️ **長時間録音は自ら計画** — 入力上限のあるすべてのエンジンは、発話範囲を事前に計画します。メモリ不足になったチャンクは半分に分割され、その分割は記憶されるため、再開した実行は失敗したリーフだけを再試行します。完了したチャンクはキャッシュされるため、同じファイルを同じ設定で再実行すると再利用されます。キャッシュはアプリでは自動（30日間操作のないエントリは削除）で、コマンドラインでは `--cache-dir` で有効になります。話者ラベルは各チャンクに引き継がれ、2つの発話が切り替わる行には両方の話者が表示されます
- ✂️ **チャンク長が設定項目に** — 設定 → 詳細調整 に、入力上限のあるモデル向けのチャンク長フィールドが追加され、エンジンが受け付ける値に制限されます（GigaAMは25秒、ParakeetとNemotronは30秒）。長時間録音は入力上限のあるすべてのエンジンで分割されます。Whisperは独自の長文処理を維持します
- 📄 **生成されるモデルドキュメント** — モデルドキュメントページのモデル一覧はカタログから生成されるため、モデル、サイズ、ダウンロードリンクはアプリが提供する内容と同期し続けます。パリティテストにより、カタログ内のすべてのファイルが有効なリンクに固定されます

## Improved

- 🗣️ **より良い話者ラベル** — 話者検出はSortformerの代わりにNVIDIA Nemotron-3-Diarizationを実行し、4人ではなく最大8人の話者を認識します。既存のインストールでは起動時に一度だけ新しいモデルが提示され、置き換えられたファイルは削除されます。断った場合は、通知とともに話者認識がオフになります
- ⚡ **GPUアクセラレーションを復活** — WindowsとLinuxのビルドでVulkanが、macOSのビルドでMetalが復活し、統合エンジンが再びGPUを使用します。使用可能なドライバーがない場合は従来どおりCPUで動作し、GPUの読み込みに失敗した場合もCPUにフォールバックします
- 🪟 **設定がウィンドウ全体に表示** — 設定を開いている間はアプリウィンドウが最大化され、設定シートがそれを埋めるため、カタログとそのフィルターのためのスペースが確保されます。設定を閉じるとウィンドウサイズが元に戻ります
- ⬇️ **読めるダウンロード表示** — ダウンロードが1件のときは、進行状況のトーストにファイル名が表示されます。複数の場合は、実行中の件数と最新ファイルの割合が表示されます。完了したカタログのダウンロードはカードがすぐにインストール済みに切り替わり、進行状況の更新はトーストだけを更新するため、モデルのダウンロード中もカタログは快適に操作できます
- 🗑️ **設定からモデルを削除** — フォルダを開かずに、使用中のものを含むダウンロード済みモデル、または単一の量子化を削除できます
- 🏷️ **Vibeの選択肢はVibeの下に** — アプリが提供する12個のWhisper GGUFビルドは、カタログとそのフィルターでVibeプロバイダーの下に表示されるようになりました。ダウンロードは引き続き同じファイル、サイズ、チェックサムに対して解決されます
- 🪟 **Wingetでフォークが維持** — Windowsインストーラーは独自のアプリと機能のエントリ（`vibe-kisev-fork`）として登録されるため、`winget upgrade` がフォークのインストールを上流のパッケージで置き換えることはなくなりました
- 🐧 **Arch Linuxへのインストール** — Linuxインストーラーは、AURから `vibe-bin` を `paru` または `yay` でインストールし、AURヘルパーがない場合は `makepkg` でビルドします
- ⏺️ **ボタンは「録音」と表示** — メインの録音ボタンは、常に実行されるとは限らない文字起こしを約束する代わりに、録音の操作だけを示すようになりました
- 🎙️ **ショートカットは選択中のマイクを使用** — 音声入力のホットキーと録音ショートカットは、システムのデフォルトではなくホームページで選択したマイクから録音します
- 🌍 **すべて翻訳済み** — カタログのインターフェースと新しい設定文字列は21の非英語アプリ言語すべてに、生成されるモデルドキュメントはウェブサイトがサポートする14の非英語言語に翻訳されました
- 🔁 **フォークのアップデート** — アプリ内アップデートはこのフォークのアップデータチャンネルを確認し、リリースノートはこのフォークの変更履歴を開きます。開発ビルドは毎コミットではなく、`dev.*` タグからオンデマンドで作成されます

## Fixed

- 👁️ **デバイス非表示の目のボタン** が、デバイスピッカーを開いているときに反応しなくなることはなくなりました — デバイスを選択せずに非表示にします
- 💥 **非表示のデバイスがある状態でデバイスピッカーを開いてもクラッシュしない** — 非表示のデバイスのグループが正しく描画されます
- 📉 **並列ダウンロードが混ざらない** — 各ダウンロードの進行状況は個別に追跡されるため、あるダウンロードが別の割合を上書きすることはなくなりました。トーストには最新ファイルの実際の割合と実行中のダウンロード数が表示されます
- 🛡️ **ダウンロードはウイルス対策のスキャンを乗り越える** — Windowsのウイルス対策が完了したファイルを保持している場合、アプリは失敗する代わりに約1分半再試行します。ほぼ完了したダウンロードは再起動をまたいで保持され、次回の試行時に再ダウンロードせずに公開されます
- 🎥 **WindowsでGoogle Meetを検出** — 会議検出は最初のブラウザプロセスだけではなく、すべてのブラウザプロセスを記憶するようになったため、ブラウザが複数のプロセスを実行していてもMeetウィンドウを見つけられます
- ⏹️ **2回目の停止でもクラッシュしない** — 録音の終了処理中に再度停止を押しても、アプリが中断されることはなく無視されます
- 🗣️ **話者の変更で行が分割** — 文の途中で話者が変わる行は、話者が変わる位置で分割され、各部分がそれぞれの話者ラベルを持ちます。チャンク化された録音も、各チャンクを0から開始する代わりに実際のタイムスタンプを報告するようになりました
- 🕒 **安定したタイムスタンプで録音が壊れない** — 安定したタイムスタンプを利用できないモデルにそれを要求した場合、文字起こしを失敗させる代わりにオプションが外れるため、その設定をオンにしたままでもGigaAMの録音がエラーにならなくなりました
- 🌐 **変更履歴が英語で一瞬表示されない** — 翻訳された変更履歴は、先に英語を描画してから直後に再レイアウトする代わりに、翻訳を待ちます
