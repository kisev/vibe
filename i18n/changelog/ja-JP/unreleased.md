## New

- 🧪 **モデルを並べて比較** — 設定 → モデル では、1つのクリップやファイルを選択したインストール済みの各モデルで実行し、ウィンドウ全体の結果を開きます。モデルごとの列に所要時間と語数、独立したスクロール、ベースラインの選択、そして見落とした単語に取り消し線を引き、余分な単語を示す単語単位の強調表示があります
- 🗣️ **比較で話者分離** — スイッチ1つで各モデルの文字起こしに話者ラベルが付くため、同じ実行でどのモデルが単語を聞き取り、誰が話したかがわかります
- 🔄 **3つのアップデートチャンネル** — Release、Beta、Dev のいずれかを追跡でき、現在のバージョンと最後に確認が実行された時刻が表示され、次の起動を待たずにボタン1つで自分で確認を開始できます
- 🗺️ **サイトにロードマップが登場** — 新しいページが、プロジェクトの計画ファイルから未アーカイブの変更をすべて直接一覧表示するため、今後の予定が手書きの推測になることはありません
- 🌐 **会議が Vibe 内で開く** — 会議リンクは独自のメニュー（戻る、進む、再読み込み、システムのブラウザで開く、閉じる）を備えた内蔵ブラウザで開き、会議ホストのリストも編集できます。Vibe は頼めば Zoom、Teams、Webex のリンクのハンドラーとして自身を登録でき、通話を検出するとマイクとシステムオーディオで録音するよう促します
- 🌍 **ウェブサイトがあなたの言語で話す** — ヘッダーの言語セレクターがページをその場で切り替え、共有リンクが選択を引き継ぐよう `?lang=` を URL に残し、右から左へのレイアウトも適用します。`/changelog/dev` が開発版のメモの恒久的なアドレスになりました

## Improved

- 🧭 **Dev アップデートに専用のライン** — 開発ビルドは Dev チャンネルの `-dev.N` プレリリースとして提供され、Beta 向けにはリリース候補が作成され、開発版の変更履歴はビルドが入れ替わっても1つの安定した URL を保ちます
- 🏷️ **比較がモデル名を正しく表示** — 結果とダイアログは、ファイル名をタイトルケースにする代わりに、カタログの正規のモデル名と量子化の表記を使用します
- 🤫 **会議検出が邪魔をしない** — Vibe 自身の会議ウィンドウは外部の検出プロンプトを抑制し、録音状態は共有されるため、Vibe で既に開いている通話が二重に録音を促すことはありません
- 🕵️ **デバイスの外には何も出ない** — テレメトリーはすべて廃止されました。アナリティクスキーも、起動時や操作時の ping も、サイト上の寄付バナーもありません。ログ、診断情報、エクスポートはディスク上に残り、自分で送信したときにだけ外へ出ます
- 📚 **ドキュメントは Diátaxis に従う** — チュートリアル、ハウツーガイド、リファレンス、解説がリポジトリ内とサイト上で分離され、「どうすれば…」と「これはどういう意味か」が1つの長いページを共有することはなくなりました
- 🔗 **リリースノートが翻訳された変更履歴を指す** — すべてのリリース本文が `https://kisev.github.io/vibe/changelog/<version>` にリンクするため、読者は英語のものではなく自分の言語を選べます

## Fixed

- 🎙️ **すべてのモデルが比較を実行できる** — GigaAM と Parakeet は VAD モデルがないという理由で実行を拒否しなくなりました。ラボが同梱の検出器を提供するため、結果はモデルだけが異なります
- 📍 **比較が先頭に** — 設定 → モデル でラボが長いモデルカタログの上に移動したため、最初に目に入ります
- 🔍 **長い文字起こしでも強調表示される** — 差分は1,000語を超えると諦めて差分ゼロを報告することはなくなりました。本当に長すぎるテキストの場合は、代わりにその列にその旨が表示されます
- 🔁 **アップデートチャンネルは名前とラインを保つ** — セレクターはどの言語でも Release、Beta、Dev と表示され、Beta は安定版ビルドをそのまま反映するのではなくリリース候補だけを提供します
- 🔌 **API サーバーのスイッチはオフのまま** — エージェントのスイッチはあなたの選択であり、再起動後も維持されます。起動時にモデルのメタデータを読み取っても、その背後でサーバーが動き続けることはなくなりました
- 🪟 **会議ウィンドウを閉じられる** — 操作はウィンドウ自体にあり、ページの読み込みに失敗しても閉じる手段のないウィンドウが残ることはなくなりました
- 🌍 **サイトがページ全体を翻訳** — 言語を切り替えても英語のセクションが残らず、変更履歴も選択した言語に従います
