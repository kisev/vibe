## New

- 🧪 **모델 비교, 나란히 보기** — 설정 → 모델에서 클립이나 파일 하나를 설치된 모델 중 선택한 각 모델로 차례로 실행하고 전체 창 결과를 엽니다. 모델마다 열이 하나씩 있고 각 열에 소요 시간과 단어 수가 표시되며, 열별로 독립적으로 스크롤되고, 기준을 고르는 선택기가 있으며, 놓친 단어는 취소선으로 긋고 추가된 단어는 표시하는 단어 수준 강조가 적용됩니다
- 🗣️ **비교에서 화자 분리** — 스위치 하나로 모든 모델의 전사에 화자 레이블이 추가되어, 같은 실행에서 어느 모델이 단어를 들었고 누가 말했는지 함께 볼 수 있습니다
- 🔄 **세 가지 업데이트 채널** — Release, Beta 또는 Dev를 따라가고, 현재 버전과 마지막 확인 시각을 확인하며, 다음 실행을 기다리지 않고 버튼 하나로 직접 확인을 시작할 수 있습니다
- 🗺️ **사이트에 로드맵이 생겼습니다** — 새 페이지가 프로젝트의 계획 파일에서 아카이브되지 않은 모든 변경 사항을 그대로 나열하므로, 앞으로 올 내용은 더 이상 손으로 쓴 추측이 아닙니다
- 🌐 **회의가 Vibe 안에서 열립니다** — 회의 링크가 자체 메뉴(뒤로, 앞으로, 새로고침, 시스템 브라우저에서 열기, 닫기)와 편집 가능한 회의 호스트 목록을 갖춘 내장 브라우저에서 열립니다. Vibe에 요청하면 Zoom, Teams, Webex 링크의 핸들러로 스스로를 등록할 수 있으며, 통화가 감지되면 마이크와 시스템 오디오로 녹음할지 묻는 안내가 표시됩니다
- 🌍 **웹사이트가 당신의 언어로 말합니다** — 헤더의 언어 선택기가 페이지를 그 자리에서 전환하고, `?lang=`을 URL에 유지해 공유 링크가 선택한 언어를 그대로 담으며, 오른쪽에서 왼쪽 레이아웃도 적용합니다. `/changelog/dev`는 이제 dev 노트의 영구 주소입니다

## Improved

- 🧭 **Dev 업데이트에 자체 라인이 생겼습니다** — dev 빌드는 Dev 채널의 `-dev.N` 프리릴리스로 배포되고, Beta용 출시 후보가 생성되며, dev 변경 내역은 빌드가 오고 가도 하나의 안정적인 URL을 유지합니다
- 🏷️ **비교가 모델 이름을 제대로 표시합니다** — 결과와 대화상자가 파일 이름의 첫 글자를 대문자로 바꾸는 대신 카탈로그의 표준 모델 이름과 양자화 표기를 사용합니다
- 🤫 **회의 감지가 방해하지 않습니다** — Vibe 자체 회의 창이 외부 감지 안내를 억제하고 녹음 상태를 공유하므로, 이미 Vibe에서 열려 있는 통화는 녹음을 두 번 제안하지 않습니다
- 🕵️ **아무것도 기기를 떠나지 않습니다** — 모든 텔레메트리가 사라졌습니다. 분석 키도, 실행 시나 동작 시의 핑도, 사이트의 후원 배너도 없습니다. 로그, 진단 정보, 내보내기 파일은 디스크에 남아 있으며 직접 보낼 때만 기기를 떠납니다
- 📚 **문서가 Diátaxis를 따릅니다** — 튜토리얼, 방법 가이드, 레퍼런스, 설명이 저장소와 사이트 모두에서 분리되어, “어떻게 하지…”와 “이게 무슨 뜻이지”가 더 이상 하나의 긴 페이지를 공유하지 않습니다
- 🔗 **릴리스 노트가 번역된 변경 내역을 가리킵니다** — 모든 릴리스 본문이 `https://kisev.github.io/vibe/changelog/<version>`로 연결되어, 독자가 영어 대신 자신의 언어를 선택할 수 있습니다

## Fixed

- 🎙️ **모든 모델이 비교를 실행할 수 있습니다** — GigaAM과 Parakeet이 VAD 모델이 없다는 이유로 실행을 거부하지 않습니다. 실험실이 번들 탐지기를 제공하므로 결과는 모델에 따라서만 달라집니다
- 📍 **비교가 맨 앞에 있습니다** — 실험실이 설정 → 모델의 긴 모델 카탈로그 위로 이동해 가장 먼저 눈에 들어옵니다
- 🔍 **긴 전사도 계속 강조됩니다** — 차이 비교가 이제 1,000단어를 넘어도 포기하지 않고 차이가 0개라고 보고하지 않습니다. 텍스트가 정말로 너무 길면 대신 해당 열에 그렇게 표시됩니다
- 🔁 **업데이트 채널이 이름과 라인을 유지합니다** — 선택기가 모든 언어에서 Release, Beta, Dev로 표시되며, Beta는 안정판 빌드를 그대로 비추는 대신 출시 후보만 제공합니다
- 🔌 **API 서버 스위치가 꺼진 상태로 유지됩니다** — 에이전트 스위치는 사용자의 선택이며 다시 시작해도 유지됩니다. 실행 시 모델 메타데이터를 읽어도 그 뒤에 서버가 계속 실행되지 않습니다
- 🪟 **회의 창을 닫을 수 있습니다** — 제어 기능이 창 자체에 있어, 페이지를 불러오지 못해도 나갈 방법이 없는 창이 남지 않습니다
- 🌍 **사이트가 페이지 전체를 번역합니다** — 언어를 바꿔도 영어 섹션이 남지 않으며, 변경 내역도 선택한 언어를 따릅니다
