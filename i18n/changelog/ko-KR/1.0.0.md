## New

- 🤖 **모델 카탈로그** — 설정 → 모델에는 번들 엔진이 불러올 수 있는 모든 ASR 모델(handy 레이어와 vibe 빌드)을 모아 둔 카탈로그가 표시됩니다. 스트리밍, 번역, 언어, 제공자별로 필터링하고, 크기가 표시된 양자화를 고르고, 클릭 한 번으로 다운로드할 수 있으며 모든 파일은 공개된 크기와 SHA-256으로 검증됩니다. 설치된 모델은 목록에서 눈에 띄게 표시되고 카드에서 바로 선택, 이름 변경, 삭제할 수 있으며, 모든 카드에서 Hugging Face 페이지로 연결됩니다
- 🧠 **모든 모델군을 위한 하나의 엔진** — GGML 런타임이 이제 transcribe.cpp 0.4.1이 되어 Parakeet, GigaAM, Nemotron, Voxtral, Qwen, Canary를 모두 불러옵니다. Whisper 전용 제어 옵션은 Whisper에서만 나타나며, 스트리밍과 번역은 실제로 불러온 모델이 지원하는 기능을 따릅니다
- 🧪 **모델 비교 실험실** — 설정 → 모델에서 짧은 클립을 녹음하거나 오디오 또는 비디오 파일을 고르고, 설치된 모델 두 개 이상을 차례로 실행한 뒤 각 받아쓰기를 타임스탬프가 붙은 comparisons 폴더에 Markdown 보고서로 저장할 수 있습니다. 모든 실행은 실제 소요 시간을 보고하며, 실패한 실행은 그 이유를 표시하고 나머지 모델은 계속 실행됩니다. 카탈로그 카드에서 빌려온 정확도와 속도 막대는 제거되었습니다 — 이제 품질은 직접 녹음한 오디오로 판단합니다
- 🎙️ **녹음 장치가 다시 연결해도 유지됨** — 선택 항목이 이름으로 장치를 찾으므로 마이크를 뺐다가 다시 꽂아도 그대로 유지됩니다. 고정된 장치가 연결 해제된 동안에는 사용할 수 없음으로 계속 표시되고, 조용히 다른 장치를 쓰는 대신 장치 이름을 알려 주며 녹음이 거부됩니다. 숨긴 장치는 계속 숨겨지며 마이크 또는 스피커 목록의 숨긴 장치 섹션에서 선택하면 다시 나타납니다
- ⏱️ **긴 녹음이 스스로 계획을 세움** — 입력 제한이 있는 모든 엔진이 음성 구간을 미리 계획합니다. 메모리가 부족해진 청크는 절반으로 나뉘고 그 분할이 기억되므로, 이어서 실행할 때는 실패한 말단 조각만 다시 시도합니다. 완료된 청크는 캐시되므로 같은 파일을 같은 설정으로 다시 실행하면 재사용합니다. 앱에서는 캐시가 자동으로 켜지고(30일 동안 손대지 않은 항목은 삭제됨), 명령줄에서는 `--cache-dir`로 선택적으로 사용할 수 있습니다. 화자 레이블은 모든 청크에 이어지며, 두 화자의 발화가 맞닿는 줄에는 두 화자가 모두 표시됩니다
- ✂️ **청크 길이가 설정 항목이 됨** — 설정 → 세부 조정에 입력 제한이 있는 모델을 위한 청크 길이 필드가 추가되었으며, 엔진이 허용하는 값으로 제한됩니다(GigaAM 25초, Parakeet과 Nemotron 30초). 긴 녹음은 입력 제한이 있는 모든 엔진에서 분할되며, Whisper는 자체 장문 처리 방식을 유지합니다
- 📄 **모델 문서 자동 생성** — Models 문서 페이지의 모델 목록이 카탈로그에서 생성되므로 모델과 크기, 다운로드 링크가 앱이 제공하는 내용과 계속 일치합니다. 일치성 테스트가 모든 카탈로그 파일을 작동하는 링크에 고정해 둡니다

## Improved

- 🗣️ **더 나은 화자 레이블** — 화자 인식이 이제 Sortformer 대신 NVIDIA Nemotron-3-Diarization을 사용하며, 4명 대신 최대 8명의 화자를 인식합니다. 기존 설치에는 시작 시 새 모델을 한 번 제안하고, 대체된 파일은 정리되며, 거절하면 안내와 함께 화자 인식이 꺼집니다
- ⚡ **GPU 가속 복원** — Windows와 Linux 빌드에는 Vulkan이, macOS 빌드에는 Metal이 돌아와 통합 엔진이 다시 GPU를 사용합니다. 사용 가능한 드라이버가 없으면 이전처럼 CPU에서 실행되며, GPU 로드에 실패해도 CPU로 대체됩니다
- 🪟 **설정이 전체 창으로 열림** — 설정이 열려 있는 동안 앱 창이 최대화되고 설정 시트가 창을 가득 채워 카탈로그와 필터를 넣을 공간이 생깁니다. 설정을 닫으면 창 크기가 복원됩니다
- ⬇️ **다운로드 진행 상황이 보임** — 다운로드가 하나 실행 중이면 진행률 토스트에 파일 이름이 표시됩니다. 여러 개면 몇 개가 실행 중인지와 가장 최근 파일의 진행률을 보여 줍니다. 끝난 카탈로그 다운로드는 카드가 즉시 설치됨으로 바뀌고, 진행률 갱신은 토스트만 새로 고치므로 모델을 다운로드하는 동안에도 카탈로그가 응답성을 유지합니다
- 🗑️ **설정에서 모델 삭제** — 폴더를 열지 않고도 다운로드한 모델(사용 중인 모델 포함)이나 개별 양자화를 제거할 수 있습니다
- 🏷️ **Vibe 추천 모델은 Vibe 아래에** — 앱이 제공하는 12개의 Whisper GGUF 빌드가 이제 카탈로그와 필터에서 Vibe 제공자 아래에 표시되며, 다운로드는 여전히 같은 파일, 크기, 체크섬을 기준으로 처리됩니다
- 🪟 **Winget이 포크를 유지함** — Windows 설치 프로그램이 자체 앱 및 기능 항목(`vibe-kisev-fork`)으로 등록되므로, `winget upgrade`가 더 이상 포크 설치를 업스트림 패키지로 교체하지 않습니다
- 🐧 **Arch Linux 설치** — Linux 설치 프로그램이 `paru` 또는 `yay`로 AUR에서 `vibe-bin`을 설치하고, AUR 헬퍼가 없으면 `makepkg`로 빌드합니다
- ⏺️ **버튼이 녹음만 표시** — 메인 녹음 버튼이 항상 실행되지는 않는 받아쓰기를 약속하는 대신, 이제 녹음 동작만 표시합니다
- 🎙️ **단축키가 선택한 마이크를 사용** — 받아쓰기 단축키와 녹음 단축키가 시스템 기본값 대신 홈 페이지에서 선택한 마이크로 녹음합니다
- 🌍 **모두 번역됨** — 카탈로그 인터페이스와 새 설정 문자열이 영어를 제외한 앱 언어 21개 모두로, 생성된 모델 문서는 웹사이트가 지원하는 영어를 제외한 14개 언어로 번역되었습니다
- 🔁 **포크 업데이트** — 앱 내 업데이트가 이 포크의 업데이터 채널을 확인하고 릴리스 노트가 이 포크의 변경 내역을 열며, dev 빌드는 매 커밋이 아니라 `dev.*` 태그에서 필요할 때 만들어집니다

## Fixed

- 👁️ **장치 숨기기 눈 버튼**이 장치 선택기가 열려 있어도 더 이상 먹통이 되지 않습니다 — 장치를 선택하지 않고 숨깁니다
- 💥 **숨긴 장치가 있는 상태에서 장치 선택기를 열어도 더 이상 충돌하지 않음** — 숨긴 장치 그룹이 올바르게 렌더링됩니다
- 📉 **병렬 다운로드가 서로 분리됨** — 각 다운로드의 진행률이 따로 추적되므로 한 다운로드가 다른 다운로드의 진행률을 덮어쓰지 않습니다. 토스트에는 가장 최근 파일의 실제 진행률과 실행 중인 다운로드 수가 표시됩니다
- 🛡️ **다운로드가 백신 검사에서 살아남음** — Windows 백신이 완료된 파일을 붙잡고 있을 때 앱이 실패하는 대신 약 1분 30초 동안 다시 시도합니다. 거의 끝난 다운로드는 재시작 후에도 유지되어, 다시 다운로드하지 않고 다음 시도에서 저장됩니다
- 🎥 **Windows에서 Google Meet 감지** — 회의 감지가 이제 첫 프로세스만이 아니라 모든 브라우저 프로세스를 기억하므로, 브라우저가 여러 프로세스를 실행 중이어도 Meet 창을 찾아냅니다
- ⏹️ **중지를 다시 눌러도 더 이상 충돌하지 않음** — 녹음을 마무리하는 중에 중지를 다시 눌러도 앱이 중단되지 않고 무시됩니다
- 🗣️ **화자가 바뀌면 줄이 분할됨** — 문장 중간에 화자가 바뀌는 줄은 이제 화자가 바뀌는 지점에서 분할되며, 각 부분은 자신의 화자 레이블을 가집니다. 청크로 나뉜 녹음도 각 청크를 0부터 시작하는 대신 실제 타임스탬프를 다시 보고합니다
- 🕒 **안정적인 타임스탬프가 더 이상 녹음을 망가뜨리지 않음** — 사용할 수 없는 모델에 안정적인 타임스탬프를 요청하면 이제 받아쓰기를 실패시키는 대신 해당 옵션을 버리므로, GigaAM 녹음이 이 설정을 켜 둔 상태에서도 더 이상 오류가 나지 않습니다
- 🌐 **변경 내역이 더 이상 영어로 깜빡이지 않음** — 번역된 변경 내역은 영어를 먼저 그린 뒤 잠시 후 다시 배치하는 대신 번역을 기다립니다
