## New

- 🧪 **并排对比模型** — “设置 → 模型”可以用同一段片段或文件，依次运行你选中的每个已安装模型，并打开全窗口结果：每个模型一列，显示其耗时和字数，各列独立滚动，可选择基准模型，单词级高亮会划掉遗漏的词并标出多出的词
- 🗣️ **对比中的发言者分离** — 一个开关即可为每个模型的转录添加发言者标签，因此同一次运行既能看出哪个模型听出了这些词，也能看出是谁说的
- 🔄 **三种更新通道** — 可跟随 Release、Beta 或 Dev，查看当前版本和上次检查的时间，并用一个按钮自行发起检查，而无需等待下次启动
- 🗺️ **网站有了路线图** — 新页面直接从项目的规划文件列出每个未归档的变更，因此即将到来的内容绝不再是手工猜测
- 🌐 **会议在 Vibe 内打开** — 会议链接会在内置浏览器中打开，该浏览器有自己的菜单（后退、前进、重新加载、在系统浏览器中打开、关闭）和可编辑的会议主机列表；只要你要求，Vibe 就能把自己注册为 Zoom、Teams 和 Webex 链接的处理程序，检测到通话时还会提示你用麦克风和系统音频录制
- 🌍 **网站会说你的语言** — 页眉中的语言选择器可就地切换页面，在 URL 中保留 `?lang=`，让分享的链接携带这一选择，并应用从右到左的布局。`/changelog/dev` 现在是开发版说明的永久地址

## Improved

- 🧭 **Dev 更新有了自己的版本线** — 开发构建以 `-dev.N` 预发布版本的形式在 Dev 通道发布，为 Beta 切出发布候选版本，开发版更新日志在构建来去之间保持一个稳定 URL
- 🏷️ **对比结果正确显示模型名称** — 结果和对话框使用目录中的规范模型名称和量化拼写，而不是把文件名改成首字母大写
- 🤫 **会议检测不再打扰** — Vibe 自己的会议窗口会抑制外部检测提示，且录音状态是共享的，因此在 Vibe 中已打开的通话绝不会再次提示录制
- 🕵️ **任何数据都不离开你的设备** — 所有遥测均已移除：没有分析密钥，启动或操作时不会发送 ping，网站上也没有捐赠横幅。日志、诊断信息和导出文件都留在磁盘上，只有你自己发送时才会离开
- 📚 **文档遵循 Diátaxis** — 教程、操作指南、参考和说明在仓库与网站上分开，因此“我该怎么做……”和“这是什么意思”不再共用同一个长页面
- 🔗 **发行说明指向已翻译的更新日志** — 每个发行说明正文都链接到 `https://kisev.github.io/vibe/changelog/<version>`，因此读者可以选择自己的语言，而不必只看英文

## Fixed

- 🎙️ **每个模型都能参与对比** — GigaAM 和 Parakeet 不再因缺少 VAD 模型而拒绝运行；实验室会提供其附带的检测器，因此结果的差异只来自模型本身
- 📍 **对比功能排在前面** — 实验室已移到“设置 → 模型”中长长的模型目录上方，因此它是你第一眼看到的内容
- 🔍 **长转录仍会高亮** — 差异对比不再在超过一千词时放弃并报告零处差异；当文本确实太长时，该列会改为说明这一点
- 🔁 **更新通道保持名称和版本线** — 选择器在所有语言中都显示 Release、Beta 和 Dev，Beta 只提供候选版本，而不再镜像稳定版本
- 🔌 **API 服务器开关保持关闭** — “代理”开关由你决定，并能在重启后保持；启动时读取模型元数据不再会在其后留下一个运行中的服务器
- 🪟 **会议窗口可以关闭了** — 它的控件就在窗口本身中，因此加载失败的页面不再留下一个无法退出的窗口
- 🌍 **网站会翻译整个页面** — 切换语言后不再残留英文区块，更新日志也会跟随所选语言
