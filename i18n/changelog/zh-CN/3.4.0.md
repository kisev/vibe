## New

- 🤖 **模型目录** — “设置 → 模型” 现在会显示一个内置目录，列出内置引擎可加载的所有 ASR 模型（handy 层加上 vibe 构建版本）。可按流式、翻译、语言或提供方筛选；选择量化版本时能看到其大小；一键下载，每个文件都会根据其公布的大小和 SHA-256 进行校验。已安装的模型在列表中更醒目，可直接在卡片上选择、重命名和删除，每张卡片都链接到其 Hugging Face 页面
- 🧠 **所有系列共用一个引擎** — GGML 运行时现在是 transcribe.cpp 0.4.1，可加载 Parakeet、GigaAM、Nemotron、Voxtral、Qwen 和 Canary。仅 Whisper 会显示其专属控件；流式与翻译遵循已加载模型实际支持的能力
- 🧪 **模型对比实验室** — “设置 → 模型” 可以录制一小段音频，或选择音频或视频文件，依次用它运行两个或更多已安装模型，并将每份转录保存为 Markdown 报告，放在带时间戳的对比文件夹中。每次运行都会报告实际耗时；失败的运行会显示原因，其余模型仍会继续运行。目录卡片上借用的准确度与速度条已移除——质量现在由你自己的音频来评判
- 🎙️ **录音设备在反复插拔后仍能保留** — 选择项按名称匹配设备，因此拔出再插回仍能保留你的麦克风；当已固定的设备不在时，它仍会以“不可用”状态显示，录音会被拒绝并指明该设备，而不是悄悄改用其他设备。已隐藏的设备保持隐藏，当从麦克风或扬声器列表的“已隐藏的设备”部分选中时便会重新出现
- ⏱️ **长录音会自行规划** — 每个有长度限制的引擎都会预先规划语音区间；出现内存不足的分块会被减半，并记住该拆分，因此恢复运行时只会重试失败的叶子分块；已完成的分块会被缓存，因此使用相同设置重新运行同一文件时会复用它们。缓存会在应用中自动启用（30 天未触碰的条目会被清除），在命令行中则需通过 `--cache-dir` 主动开启。发言者标签会带入每个分块，两个发言轮次交界处的行会显示两位发言者
- ✂️ **分块长度是一项设置** — “设置 → 调优” 新增了分块长度字段，适用于有输入上限的模型，并限制在引擎可接受的范围内（GigaAM 为 25 秒，Parakeet 和 Nemotron 为 30 秒）。所有有长度限制的引擎都会拆分长录音；Whisper 保留其自身的长音频处理方式
- 📄 **生成的模型文档** — 模型文档页面上的模型列表由目录生成，因此模型、其大小和下载链接与应用提供的内容保持一致；一项一致性测试确保每个目录文件都固定指向可用的链接

## Improved

- 🗣️ **更好的发言者标签** — 发言者识别现在运行 NVIDIA Nemotron-3-Diarization，而不是 Sortformer，最多可识别八位发言者，而不是四位。现有安装在启动时会收到一次新模型的下载提示，被取代的文件会被清理，拒绝后会关闭发言者识别并给出提示
- ⚡ **GPU 加速恢复** — Windows 和 Linux 构建版本重新支持 Vulkan，macOS 构建版本重新支持 Metal，因此统一引擎再次使用 GPU；没有可用的驱动时照旧在 CPU 上运行，GPU 加载失败时仍会回退到 CPU
- 🪟 **设置以全窗口打开** — 打开设置时应用窗口会最大化，设置面板会填满窗口，为目录及其筛选器留出空间；关闭设置后会恢复你的窗口大小
- ⬇️ **清晰可读的下载进度** — 单个下载进行时，进度提示会显示其文件名；有多个下载时，会显示正在运行的数量以及最新文件的百分比。目录下载完成后，其卡片会立即变为“已安装”，进度更新只刷新提示，因此模型下载期间目录仍保持响应
- 🗑️ **从设置中删除模型** — 无需打开文件夹即可删除已下载的模型（包括正在使用的模型）或单个量化版本
- 🏷️ **Vibe 精选模型归入 Vibe 之下** — 应用提供的十二个 Whisper GGUF 构建版本现在在目录及其筛选器中显示在 Vibe 提供方之下，而它们的下载仍指向相同的文件、大小和校验和
- 🪟 **Winget 保留分支版本** — Windows 安装程序会注册为独立的应用和功能条目（`vibe-kisev-fork`），因此 `winget upgrade` 不再用上游软件包替换分支安装
- 🐧 **Arch Linux 安装** — Linux 安装程序会通过 `paru` 或 `yay` 从 AUR 安装 `vibe-bin`，在没有 AUR 助手时则使用 `makepkg` 构建
- ⏺️ **按钮显示“录音”** — 主录音按钮现在只表示录音操作，而不再承诺它并不总会执行的转录
- 🎙️ **快捷键使用你的麦克风** — 听写热键和录音快捷键会使用首页所选麦克风录音，而不是系统默认麦克风
- 🌍 **全部已翻译** — 目录界面和新增设置字符串已翻译为应用支持的全部 21 种非英语语言，生成的模型文档也已翻译为网站支持的 14 种非英语语言
- 🔁 **分支更新** — 应用内更新会检查这个分支的更新通道，发行说明会打开这个分支的更新日志，开发构建按需从 `dev.*` 标签构建，而不是每次提交都构建

## Fixed

- 👁️ **隐藏设备的眼睛按钮**在设备选择器打开时不再失效——它会隐藏该设备，而不会选中它
- 💥 **存在隐藏设备时打开设备选择器不再崩溃**——已隐藏设备分组能正确渲染
- 📉 **并行下载保持独立** — 每个下载的进度单独跟踪，因此一个下载不再覆盖另一个的百分比；提示会显示最新文件的真实百分比以及正在进行的下载数量
- 🛡️ **下载能经受防病毒扫描** — 当 Windows 防病毒软件占用已完成的文件时，应用会重试约一分半钟，而不是直接失败；接近完成的下载会在重启后保留，并在下一次尝试时发布，而无需重新下载
- 🎥 **在 Windows 上检测 Google Meet** — 会议检测现在会记住每个浏览器进程，而不只是第一个，因此即使浏览器运行多个进程，也能找到 Meet 窗口
- ⏹️ **再次点击“停止”不再崩溃** — 在录音即将完成时再次按下停止会被忽略，而不会中止应用
- 🗣️ **发言者变化会拆分行** — 句子中途切换发言者的行现在会在发言者变化处拆分，每个部分都带有各自的发言者标签。分块录音也会重新报告真实时间戳，而不是每个分块都从零开始
- 🕒 **稳定时间戳不再破坏录音** — 在无法使用稳定时间戳的模型上请求稳定时间戳时，现在会放弃该选项，而不是让转录失败，因此即使保持该偏好开启，GigaAM 录音也不再报错
- 🌐 **更新日志不再闪现英文** — 已翻译的更新日志会等待其译文，而不是先显示英文、片刻后再重新排版
