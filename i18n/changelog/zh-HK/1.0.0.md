## New

- 🤖 **模型目錄** — 設定 → 模型 會顯示內置目錄,列出內置引擎可載入的每個 ASR 模型(handy 層加上 vibe 構建版本)。可按串流、翻譯、語言或供應商篩選;選擇量化時會顯示其大小;一鍵下載,每個檔案都會按公佈的大小和 SHA-256 驗證。已安裝的模型會在清單中突出顯示,可直接在卡片上選取、重新命名和刪除,而且每張卡片都連結到其 Hugging Face 頁面
- 🧠 **一個引擎支援所有模型家族** — GGML 執行環境現為 transcribe.cpp 0.4.1,可同樣載入 Parakeet、GigaAM、Nemotron、Voxtral、Qwen 和 Canary。僅限 Whisper 的控制項只會在 Whisper 時出現;串流和翻譯會跟隨所載入模型實際支援的功能
- 🧪 **模型比較實驗室** — 設定 → 模型 可以錄製一段短片段,或選擇音頻或影片檔案,依次用兩個或以上已安裝模型執行,並將每份轉錄儲存為 Markdown 報告,放在以時間戳命名的比較資料夾中。每次執行都會報告其實際耗時;失敗的執行會顯示原因,其餘模型仍會繼續執行。借用而來的準確度和速度指標已從目錄卡片移除——品質現在以你自己的音頻來判斷
- 🎙️ **錄音裝置經得起重新插拔** — 選擇會按名稱比對裝置,因此拔除再插回後仍會保留你的麥克風;當已固定的裝置不在時,它會顯示為無法使用,錄音會被拒絕並指出該裝置名稱,而不是悄悄改用另一個。已隱藏的裝置會保持隱藏,當你從麥克風或揚聲器清單的「已隱藏的裝置」區段選取時便會重新出現
- ⏱️ **長錄音會自行規劃** — 每個設有上限的引擎都會預先規劃其語音範圍;記憶體不足的分塊會被對半切分,而該切分會被記住,因此重新開始的執行只會重試失敗的末端分塊;已完成的分塊會被快取,所以以相同設定重新執行同一檔案時會重用它們。快取在應用程式中自動運作(30 天內未動過的項目會被清除),在命令列則需以 `--cache-dir` 主動啟用。發言者標籤會帶入每個分塊,而兩段發言交界處的行會顯示兩位發言者
- ✂️ **分塊長度是一項設定** — 設定 → 微調 為設有輸入上限的模型新增分塊長度欄位,並限制在引擎可接受的範圍內(GigaAM 為 25 秒,Parakeet 和 Nemotron 為 30 秒)。每個設有上限的引擎都會分割長錄音;Whisper 則保留其本身的長篇處理方式
- 📄 **自動生成的模型文件** — 模型文件頁面上的模型清單由目錄生成,因此模型、其大小和下載連結都會與應用程式提供的內容保持一致;一項對等測試會確保每個目錄檔案都固定指向可用的連結

## Improved

- 🗣️ **更佳的發言者標籤** — 發言者識別現在改用 NVIDIA Nemotron-3-Diarization 而非 Sortformer,可識別多達八位發言者,而非四位。現有安裝會在啟動時獲提供一次新模型,被取代的檔案會被清理,若拒絕則會關閉發言者識別並顯示通知
- ⚡ **GPU 加速恢復** — Vulkan 已回到 Windows 和 Linux 構建版本,Metal 已回到 macOS 構建版本,因此統一引擎會再次使用 GPU;沒有可用的驅動程式時會一如以往在 CPU 上執行,而 GPU 載入失敗時仍會退回 CPU
- 🪟 **設定以全視窗開啟** — 開啟設定時應用程式視窗會最大化,設定面板會填滿視窗,為目錄及其篩選器留出空間;關閉設定後會還原你的視窗大小
- ⬇️ **看得懂的下載** — 當一個下載正在進行時,進度提示會顯示其檔案名稱;若有多個下載,則會顯示正在進行的數目和最新檔案的百分比。完成後,目錄下載的卡片會即時轉為已安裝,而進度更新只會重新整理提示,因此模型下載期間目錄仍保持流暢
- 🗑️ **從設定刪除模型** — 無需開啟資料夾,即可移除已下載的模型(包括正在使用的模型)或單一量化版本
- 🏷️ **Vibe 精選歸於 Vibe 之下** — 應用程式提供的十二個 Whisper GGUF 構建版本,現在會在目錄及其篩選器中顯示於 Vibe 供應商之下,而其下載仍對應相同的檔案、大小和校驗碼
- 🪟 **Winget 保留分支版本** — Windows 安裝程式會註冊為獨立的「應用程式與功能」項目(`vibe-kisev-fork`),因此 `winget upgrade` 不會再以原廠套件取代分支版本的安裝
- 🐧 **Arch Linux 安裝** — Linux 安裝程式會以 `paru` 或 `yay` 從 AUR 安裝 `vibe-bin`,若沒有 AUR 輔助工具,則以 `makepkg` 構建
- ⏺️ **按鈕寫著「錄音」** — 主要錄音按鈕現在只標示錄音動作,而不再承諾並非每次都執行的轉錄
- 🎙️ **快捷鍵使用你的麥克風** — 聽寫快捷鍵和錄音快捷鍵會使用主頁所選的麥克風錄音,而非系統預設裝置
- 🌍 **全部已翻譯** — 目錄介面和新的設定字串已翻譯成全部 21 種非英文應用程式語言,而自動生成的模型文件則翻譯成網站支援的 14 種非英文語言
- 🔁 **分支版本更新** — 應用程式內更新會檢查此分支的更新通道,發行說明會開啟此分支的更新日誌,而開發構建版本會按需從 `dev.*` 標籤產生,而非每次提交都產生

## Fixed

- 👁️ **隱藏裝置的眼睛按鈕** 在裝置選擇器開啟時不會再失效——它會隱藏該裝置而不選取它
- 💥 **在存在已隱藏裝置時開啟裝置選擇器不會再當機** — 已隱藏裝置群組會正確顯示
- 📉 **並行下載各自獨立** — 每個下載的進度都會獨立追蹤,因此一個下載不會再覆蓋另一個下載的百分比;提示會顯示最新檔案的真實百分比以及正在進行的下載數目
- 🛡️ **下載能度過防毒掃描** — 當 Windows 防毒軟件鎖定已完成的檔案時,應用程式會重試約一分半鐘而不是直接失敗;接近完成的下載會保留到重新啟動之後,並在下次嘗試時發佈,而無需重新下載
- 🎥 **在 Windows 上偵測到 Google Meet** — 會議偵測現在會記住每個瀏覽器程序,而不只是第一個,因此即使瀏覽器執行多個程序,也能找到 Meet 視窗
- ⏹️ **第二次按停止不會再當機** — 錄音完成期間再次按停止會被忽略,而不是中止應用程式
- 🗣️ **發言者變更會分割該行** — 句子中途轉換發言者的行,現在會在發言者變更處分割,每部分各自帶有發言者標籤。分塊錄音亦會再次報告真實時間碼,而不是每個分塊都從零開始
- 🕒 **穩定時間碼不會再令錄音失敗** — 對無法使用穩定時間碼的模型要求該選項時,現在會捨棄該選項,而不是令轉錄失敗,因此 GigaAM 錄音不會再因為此偏好設定仍開啟而報錯
- 🌐 **更新日誌不會再閃現英文** — 已翻譯的更新日誌會等待其譯文,而不是先顯示英文,片刻後再重新排版
