## New

- 🤖 **Каталог моделей** — Настройки → Модели показывают встроенный каталог всех ASR-моделей, которые может загрузить встроенный движок (слой handy плюс сборки vibe). Фильтруйте по потоковому распознаванию, переводу, языку или провайдеру; выбирайте квантование с указанием размера; скачивайте одним нажатием — каждый файл сверяется с опубликованным размером и SHA-256. Установленные модели выделяются в списке, а выбрать, переименовать и удалить можно прямо на карточке; каждая карточка ссылается на свою страницу на Hugging Face
- 🧠 **Один движок для всех семейств** — среда GGML теперь transcribe.cpp 0.4.1 и загружает Parakeet, GigaAM, Nemotron, Voxtral, Qwen и Canary одинаково. Настройки только для Whisper показываются лишь для Whisper; потоковое распознавание и перевод зависят от того, что на самом деле поддерживает загруженная модель
- 🧪 **Лаборатория сравнения моделей** — в Настройках → Моделях можно записать короткий фрагмент или выбрать аудио- или видеофайл, прогнать по нему две или более установленные модели одну за другой и сохранить каждую транскрипцию как отчёт Markdown в папку сравнений с отметкой времени. Каждый запуск сообщает своё реальное время; неудачный запуск показывает причину, а остальные модели всё равно выполняются. Заимствованные шкалы точности и скорости убраны с карточек каталога — качество теперь оценивается на вашем собственном аудио
- 🎙️ **Устройства записи переживают переподключение** — выбор сопоставляет устройства по имени, поэтому после отключения и повторного подключения микрофон сохраняется; пока закреплённое устройство отсутствует, оно остаётся в списке как недоступное, а запись отклоняется с указанием устройства вместо тихой подмены на другое. Скрытые устройства остаются скрытыми и возвращаются, когда их выбирают в разделе «Скрытые устройства» списка микрофонов или динамиков
- ⏱️ **Длинные записи планируют себя сами** — каждый ограниченный движок заранее планирует речевые диапазоны; фрагмент, на котором не хватило памяти, делится пополам, и это разделение запоминается, поэтому при возобновлении повторяются только неудавшиеся листья; завершённые фрагменты кэшируются, и повторный запуск того же файла с теми же настройками использует их. В приложении кэш работает автоматически (записи, к которым не обращались 30 дней, удаляются), а в командной строке включается вручную с помощью `--cache-dir`. Метки говорящих переносятся в каждый фрагмент, а строки на стыке двух реплик показывают обоих говорящих
- ✂️ **Длина фрагмента — это настройка** — в Настройках → Тонкой настройке появляется поле длины фрагмента для моделей с ограничением на вход, приведённое к тому, что принимает движок (25 с для GigaAM, 30 с для Parakeet и Nemotron). Длинные записи делятся для каждого ограниченного движка; Whisper сохраняет собственную обработку длинных записей
- 📄 **Сгенерированная документация моделей** — список моделей на странице документации «Модели» генерируется из каталога, поэтому модели, их размеры и ссылки на скачивание совпадают с тем, что предлагает приложение; тест на соответствие проверяет, что каждый файл каталога закреплён за рабочей ссылкой

## Improved

- 🗣️ **Лучшие метки говорящих** — обнаружение говорящих теперь работает на NVIDIA Nemotron-3-Diarization вместо Sortformer и распознаёт до восьми говорящих вместо четырёх. Существующим установкам новая модель предлагается один раз при запуске, заменённые файлы очищаются, а при отказе распознавание говорящих выключается с уведомлением
- ⚡ **Ускорение GPU восстановлено** — Vulkan снова доступен в сборках для Windows и Linux, а Metal — в сборке для macOS, поэтому единый движок опять использует GPU; без работоспособного драйвера он, как и раньше, работает на CPU, а при неудачной загрузке GPU по-прежнему переключается на CPU
- 🪟 **Настройки открываются на всё окно** — пока настройки открыты, окно приложения разворачивается, и панель занимает его целиком, оставляя место для каталога и его фильтров; при закрытии настроек размер окна восстанавливается
- ⬇️ **Понятные загрузки** — пока идёт одна загрузка, во всплывающем уведомлении о ходе указано имя её файла; при нескольких там показано, сколько их выполняется, и процент последнего файла. Завершённая загрузка из каталога сразу переключает карточку в состояние «Установлена», а обновления хода обновляют только уведомление, поэтому каталог остаётся отзывчивым, пока модель скачивается
- 🗑️ **Удаление моделей из настроек** — удалите скачанную модель, включая используемую сейчас, или отдельное квантование, не открывая папку
- 🏷️ **Выбор Vibe — под провайдером Vibe** — двенадцать сборок Whisper GGUF, которые предлагает приложение, теперь отображаются под провайдером Vibe в каталоге и его фильтре, а их загрузки по-прежнему ссылаются на те же файлы, размеры и контрольные суммы
- 🪟 **Winget сохраняет форк** — установщик Windows регистрируется отдельной записью в списке «Приложения и возможности» (`vibe-kisev-fork`), поэтому `winget upgrade` больше не заменяет установленный форк пакетом из апстрима
- 🐧 **Установка на Arch Linux** — установщик для Linux ставит `vibe-bin` из AUR с помощью `paru` или `yay`, а при отсутствии помощника AUR собирает его через `makepkg`
- ⏺️ **На кнопке написано «Записать»** — основная кнопка записи теперь называет только действие записи, а не обещает транскрипцию, которая выполняется не всегда
- 🎙️ **Сочетания клавиш используют ваш микрофон** — горячая клавиша диктовки и сочетание клавиш записи записывают с микрофона, выбранного на главной странице, а не с системного по умолчанию
- 🌍 **Всё переведено** — интерфейс каталога и новые строки настроек переведены на все 21 неанглийских языка приложения, а сгенерированная документация моделей — на 14 неанглийских языков, которые поддерживает сайт
- 🔁 **Обновления форка** — обновления в приложении проверяют канал обновлений этого форка, а примечания к выпуску открывают журнал изменений форка; dev-сборки создаются по требованию из тегов `dev.*`, а не из каждого коммита

## Fixed

- 👁️ **Кнопка глаза для скрытия устройств** больше не перестаёт работать, когда открыт выбор устройства — она скрывает устройство, не выбирая его
- 💥 **Открытие выбора устройства при наличии скрытых устройств больше не приводит к падению** — группа скрытых устройств отображается корректно
- 📉 **Параллельные загрузки не смешиваются** — ход каждой загрузки отслеживается отдельно, поэтому одна загрузка больше не перезаписывает процент другой; уведомление показывает реальный процент последнего файла и сколько загрузок выполняется
- 🛡️ **Загрузки переживают проверку антивирусом** — когда антивирус Windows удерживает готовый файл, приложение повторяет попытки примерно полторы минуты вместо ошибки; почти завершённая загрузка сохраняется между перезапусками и публикуется при следующей попытке без повторного скачивания
- 🎥 **Google Meet обнаруживается в Windows** — определение встреч теперь запоминает каждый процесс браузера, а не только первый, поэтому находит окно Meet, даже когда браузер запускает несколько процессов
- ⏹️ **Повторное нажатие «Остановить» больше не приводит к падению** — повторное нажатие остановки, пока запись завершается, игнорируется, а не аварийно закрывает приложение
- 🗣️ **Смена говорящего разбивает строку** — строка, в которой говорящий меняется посреди предложения, теперь разделяется в месте смены, и каждая часть несёт свою метку говорящего. Записи, разбитые на фрагменты, снова сообщают реальные метки времени вместо того, чтобы начинать каждый фрагмент с нуля
- 🕒 **Стабильные метки времени больше не ломают запись** — запрос стабильных меток времени к модели, которая не может их использовать, теперь сбрасывает эту опцию вместо сбоя транскрипции, поэтому записи на GigaAM больше не завершаются ошибкой при включённой настройке
- 🌐 **Журнал изменений больше не мелькает английским** — переведённый журнал изменений ждёт свой перевод, а не показывает сначала английский текст и не перестраивается мгновение спустя
