# Поддържани формати

Vibe приема аудио и видео файлове и експортира транскрипции в няколко текстови формата. Настолното приложение нормализира медията с ffmpeg преди транскрибирането; в Linux се изисква системният `ffmpeg`, докато пакетите за macOS и Windows носят свой.

## Вход

| Вид | Разширения |
| --- | --- |
| Аудио | `mp3`, `wav`, `aac`, `flac`, `oga`, `ogg`, `opus`, `m4a`, `m4b`, `wma` |
| Видео | `mp4`, `mkv`, `avi`, `mov`, `wmv`, `webm`, `mxf` |

Контейнер извън този списък може да проработи, ако ffmpeg може да го декодира; конвертирайте го първо, ако приложението го отхвърли.

## Експорт от настолното приложение

Отворете диалога за експорт на транскрипция и изберете един от следните:

| Формат | Съдържание |
| --- | --- |
| TXT | Обикновен текст без форматиране |
| Markdown | Заглавия и форматиран текст |
| SRT | Номерирани субтитри с времеви маркери |
| VTT | Уеб субтитри WebVTT с времеви маркери |
| HTML | Стилизирана уеб страница |
| JSON | Структурирани данни за транскрипцията и времето |
| CSV | Редове, готови за електронна таблица |
| DOCX | Форматиран документ на Word |
| PDF | Документ за печат |

Опциите за експорт също превключват времевите маркери и етикетите на говорещите, където форматът ги поддържа. Автоматичният експорт може да записва всеки от тези формати до записа, в папката за проекти или в папка по ваш избор.

## Изход от CLI

`vibe-server transcribe` записва `txt` (по подразбиране), `markdown` (псевдоним `md`), `json`, `srt` или `vtt`. `--output` записва нов файл и отказва да презапише съществуващ път. Вижте [Команден ред](/vibe/docs#cli).
