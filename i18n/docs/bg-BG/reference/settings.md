# Настройки и конфигурация

Настройките се съхраняват в `app_config.json` в конфигурационната директория на приложението. Файлът е предназначен за четене и редактиране: Vibe го наблюдава и прилага външна промяна без рестартиране. **Настройки → Агенти → Конфигурационен файл** го отваря.

## Местоположение на конфигурационния файл

| Платформа | Директория |
| --- | --- |
| macOS | `~/Library/Application Support/github.com.thewh1teagle.vibe` |
| Windows | `%appdata%\github.com.thewh1teagle.vibe` |
| Linux | `~/.config/github.com.thewh1teagle.vibe` |

Директорията запазва идентификатора си от upstream, така че името е непроменено от по-ранните компилации.

## Раздели с настройки

| Раздел | Съдържа |
| --- | --- |
| Общи | Език на интерфейса, тема, актуализации, оставане в трей, стартиране при влизане в системата, предотвратяване на заспиването |
| Поверителност | Дали проектите се запазват и политиката за поверителност |
| Транскрипция | Език, автоматичен експорт, звук и фокусиране при завършване, папка за проекти |
| Модели | Избор CPU/GPU, GPU устройство, каталог с модели, модел за разделяне на говорещи |
| Фина настройка | Настройки на Whisper, обработка на звука, памет на модела и време за освобождаване |
| Запис | Браузър за срещи, откриване на срещи, автоматично транскрибиране, клавишна комбинация за запис, разрешения в macOS |
| Диктовка | Клавишна комбинация за диктовка и режим на активиране |
| ИИ | Резюмета и задачи за диктовка, връзка с платформата |
| Телефон | Прехвърляне от телефон, сдвояване, сдвоени устройства |
| Агенти | Локален API, Agent Skill, конфигурационен файл |
| Разширени | Логове, диагностика и контроли за разработчици |

## Стойности, които си струва да знаете

| Група ключове | Значение |
| --- | --- |
| `transcription.*` | Език, подсказка, диаризация, времеви маркери, разделяне на дълги записи на фрагменти |
| `model.*` | Избран модел, показвани имена, GPU устройство, превключвател само CPU, време за освобождаване |
| `transcript.*` | Формат за експорт, времеви маркери, говорещи, автоматичен експорт |
| `recording.*` | Входни и изходни устройства, откриване на срещи, клавишна комбинация за запис |
| `ai.*` | Платформа, базов URL, ключ, модел, подсказка и превключватели за всяка задача |
| `general.updateChannel` | `stable`, `beta` или `dev` |
| `handoff.pairing` | Сдвоени телефонни устройства и хешове на идентификационните данни |

Точните имена на полетата са достатъчно стабилни за редактиране, но схемата принадлежи на приложението: променяйте стойност през интерфейса за настройки, когато има такава, и оставете приложението да пренапише файла, вместо да го заменяте изцяло.
