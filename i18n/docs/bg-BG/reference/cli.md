# Команден ред

Изпълнимият файл `vibe` е настолното приложение. Когато получи аргумент, различен от `--hidden`, той препраща аргументите към вградения `vibe-server` и отпечатва изхода на този процес, така че CLI и прозорецът използват един и същ двигател и модели.

Сървърният двоичен файл е `vibe-server`; работно копие за разработка може да го извика директно. `--help` на всяка от двете входни точки отпечатва текущите флагове.

## Подкоманди

| Команда | Предназначение |
| --- | --- |
| `transcribe <model> <audio>` | Транскрибира един файл и отпечатва или записва резултата |
| `serve [model]` | Стартира локалния HTTP сървър с документация Swagger |
| `pull <url>` | Изтегля модел или друг файл |
| `devices` | Изброява GPU устройствата като JSON |

## Опции на transcribe

| Опция | Ефект |
| --- | --- |
| `--format <txt\|markdown\|md\|json\|srt\|vtt>` | Формат на изхода; по подразбиране `txt` |
| `--output <path>` | Записва в нов файл; отказва презаписване |
| `-l`, `--language <code>` | Код на езика |
| `--detect-language` | Открива езика |
| `--translate` | Превежда на английски, където моделът го поддържа |
| `--vad-model <path>` | Модел Silero VAD, изискван от някои семейства за дълго аудио |
| `--diarize-model <path>` | Модел за диаризация на говорещи |
| `--prompt <text>` | Начална подсказка, за модели, които я използват |
| `--word-timestamps` | Извежда времеви маркери на ниво дума, където се поддържа |
| `--threads <n>` | Нишки на CPU |
| `--gpu-device <n>` | Индекс на GPU устройство, започващ от 1; `0` или отрицателно означава автоматично |
| `--cache-dir <dir>` | Запазва завършените фрагменти, за да се възобнови прекъснато изпълнение |
| `--chunk-seconds <n>` | Планирана дължина на фрагмент, ограничена от прозореца на модела |

`--enhance-audio`, `--temperature`, `--max-text-ctx`, `--max-segment-len`, `--best-of` и `--beam-size` настройват двигателя; изпълнете `--help` за стойностите им по подразбиране.

## Опции на serve

| Опция | Ефект |
| --- | --- |
| `--host <ip>` | Адрес за свързване; по подразбиране `127.0.0.1` |
| `-p`, `--port <port>` | Порт; `0` избира свободен |
| `--exit-with-parent` | Спира с родителския процес |
| `--unload-timeout <value>` | Освобождава бездействащ модел |
| `--cache-dir <dir>` | Директория за кеша на фрагментите |

**Настройки → Агенти** стартира същия сървър от приложението и дава връзка към документацията му Swagger.

## Примери

```console
vibe transcribe model.gguf recording.wav --format srt --output recording.srt
vibe transcribe model.gguf recording.wav --language ru --vad-model ggml-silero-v6.2.0.bin
vibe devices
vibe serve --port 0
```
