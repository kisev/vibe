# 切换更新通道

Vibe 会检查三个更新通道之一：Release、Beta 或 Dev。通道决定应用提供哪些构建，而且只会向前移动。

## 选择通道

1. 打开**设置 → 通用 → 更新**。
1. 选择 **Release**、**Beta** 或 **Dev**。
1. 按**检查更新**。

同一区域还会显示已安装版本、上次检查时间和结果。启动时也会执行检查。

## 各通道提供的内容

| 通道 | 构建版本 |
| --- | --- |
| Release | 稳定版本 |
| Beta | 下一个稳定版本的候选版本 |
| Dev | 最新的 `dev` 构建 |

选择了 Dev 的 Release 或 Beta 安装会看到**已是最新版本**：每个 dev 构建的排序都低于它当前运行的版本。转到 dev 线需要手动安装一次 dev 构建；之后 Dev 通道会将其向前更新。

Beta 安装通过切换到 Release 来迁移到最终版本，因为稳定版本的排序高于其候选版本。
