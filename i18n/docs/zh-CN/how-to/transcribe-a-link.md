# 从链接转录

Vibe 使用 yt-dlp 下载媒体 URL 背后的音频并转录结果。支持的网站就是 yt-dlp 支持的网站；当某个网站失效时，更新 yt-dlp 通常能修复。

## 发送链接

1. 打开 Vibe 并选择**从链接**。
1. 粘贴一个 URL，或用空白分隔粘贴多个 URL 以全部加入队列。
1. 按**开始转录**。

首次使用链接时，Vibe 会询问是否安装 yt-dlp；网站失败时会询问是否更新。下载的音频是临时的；转录文本会像其他项目一样保存。

## 预期情况

- 单个链接会在下载完成后立即开始。
- 队列一次运行一个链接，并按项目显示进度。
- 权重、模型和转录文本都留在本地。下载本身会访问媒体主机，并为获取 yt-dlp 访问 GitHub。
