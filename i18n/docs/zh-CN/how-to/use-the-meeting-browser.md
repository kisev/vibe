# 使用会议浏览器

Vibe 可以在自己的窗口中承载通话，并带有一个始终置顶的栏，其主要操作是**录制此会议**。该窗口使用平台 webview；[会议浏览器为何这样工作](/vibe/docs#meeting-browser)涵盖了隔离和限制。

## 在 Vibe 中打开通话

使用以下任一方式：

- 打开**设置 → 录音 → 在 Vibe 中打开**，粘贴链接，然后打开。
- 从其他应用、脚本或快捷方式调用 `vibe://open/?url=https://…`。Vibe 只接受格式正确的 https URL，其他内容会以对话框拒绝。
- 在**设置 → 录音**下开启**在 Vibe 中打开会议链接**，以注册 Zoom、Teams 和 Webex 链接。此功能在 Windows 和 Linux 上可用，macOS 不可用。

在 Chrome、Edge 或 Firefox 中点击 https 链接仍会打开该浏览器。Vibe 不会注册为默认浏览器。

## 获取录制栏

**设置 → 录音 → 会议主机**列出了会获得会议栏的主机。默认值是 `telemost.yandex.ru` 和 `stream.wb.ru`。

- 添加主机会使其链接成为可录制会话。
- 移除主机会失去该栏；其链接仍会在浏览器窗口中打开。

匹配基于 https 之上的主机名，因此 `sub.telemost.yandex.ru` 会匹配 `telemost.yandex.ru` 条目，而 `http` URL 不会。该列表是便利筛选器，不是安全边界：每个 https 链接都会在窗口中打开，但只有列出的主机才会获得该栏。

## 录制通话

1. 在 Vibe 中打开会议。
1. 在通话前或通话中按**录制此会议**。
1. 从栏或主窗口停止。

录音是手动的；会议窗口绝不会自行开始录音。录制器会捕获配置好的麦克风，并在启用时捕获系统音频回环，因此通话双方都会被录下。

录音时关闭窗口会询问是停止还是在后台继续录音。

## 回退到系统浏览器

如果服务拒绝在嵌入式 webview 中运行，请使用栏中的**在系统浏览器中打开**。这是对 DRM 较重或对 WebRTC 不友好的网站的支持回退方式。
