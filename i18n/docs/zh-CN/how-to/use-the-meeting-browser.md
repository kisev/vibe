# 使用会议浏览器

Vibe 可以在自己的基于 Chromium 的窗口中承载通话：应用的浏览器界面（地址、后退、前进、重新加载、在外部打开、关闭和**录制此会议**）位于顶部，页面占据同一窗口的其余部分。没有单独的栏窗口。URL 方案和允许列表见[会议浏览器参考](../reference/meeting-browser.md)，该机制为何这样工作见[说明](../explanation/meeting-browser.md)。

## 在 Vibe 中打开通话

使用以下任一方式：

- 从其他应用或系统：在**设置 → 录音**下开启**在 Vibe 中打开会议链接**，以注册 Zoom、Teams 和 Webex 链接（Windows 和 Linux，不含 macOS）。应用会验证映射后的 URL，并在其主机允许加载时于浏览器窗口中打开，否则交给系统浏览器。
- 在 Vibe 内：主页的**会议浏览器**来源，或**设置 → 录音 → 在 Vibe 中打开**；粘贴链接并按下**在 Vibe 中打开**。
- 链接的主机必须在允许列表中；列表之外的顶级导航和跨源资源会被拒绝。浏览器界面的录制控件出现在每个允许的页面上。

在 Chrome、Edge 或 Firefox 中点击 https 链接仍会打开该浏览器。Vibe 不会注册为默认浏览器。

## 录制通话

1. 在 Vibe 中打开会议。
1. 在通话前或通话中，在窗口的浏览器界面中按下**录制此会议**。
1. 从浏览器界面或主窗口停止。

录音是手动的；会议窗口绝不会自行开始录音。录制器会捕获配置好的麦克风，并在启用时捕获系统音频回环，因此通话双方都会被录下。

浏览器界面中的麦克风和扬声器选择器更改的是主窗口使用的同一组设备，因此无需离开通话即可切换路由。录音进行时，它们会被禁用并显示正在捕获的设备；本次录音未捕获的音源会显示**无记录**。

录音时关闭窗口会询问是停止还是在后台继续录音。

## 允许你使用的网站

**设置 → 录音 → 允许的域名**是浏览器的允许列表；它一开始为空。添加你需要的每个域名，其子域名会通过 https 自动包含在内。

只有列出的域名可以加载。指向其他主机的链接会被拒绝，允许的页面从未列出的源拉取的任何脚本、字体或图像也会被拒绝。被拒绝的主机会出现在**已阻止**下，并带有**允许**操作，会添加该域名并重新加载页面。浏览器界面在拒绝导航时也会给出同样的提议。

严格的列表可能会让资源来自 CDN 的页面在允许该 CDN 之前无法正常工作；这是有意为之的取舍，而已阻止列表让修复只需一次点击。

## 回退到系统浏览器

如果服务拒绝在嵌入式 webview 中运行，请使用浏览器界面中的**在系统浏览器中打开**。对于 DRM 较重或对 WebRTC 不友好的网站，系统浏览器是受支持的回退方式。

在 macOS 上，嵌入式浏览器没有窗口内的浏览器界面：页面会在纯页面窗口中打开，录音仍可从主窗口使用，而系统浏览器是整通通话的回退方案。
