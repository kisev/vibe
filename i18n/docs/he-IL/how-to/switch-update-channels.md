# החלפת ערוצי עדכון

Vibe בודק אחד משלושה ערוצי עדכון: Release, Beta או Dev. הערוץ קובע אילו בילדים האפליקציה מציעה, והוא תמיד מתקדם רק קדימה.

## בחירת ערוץ

1. פתחו את **הגדרות → כללי → עדכונים**.
1. בחרו **Release**, **Beta** או **Dev**.
1. לחצו על **בדוק עדכונים**.

אותו מדור מציג את הגרסה המותקנת, זמן הבדיקה האחרונה והתוצאה. הבדיקה גם רצה באתחול.

## מה כל ערוץ נושא

| ערוץ | בילדים |
| --- | --- |
| Release | גרסאות יציבות |
| Beta | מועמדי שחרור לגרסה היציבה הבאה |
| Dev | בילדי ה-`dev` החדשים ביותר |

התקנת Release או Beta שבוחרת Dev מציגה **מעודכן**: כל בילד dev מדורג מתחת לגרסה שכבר רצה. המעבר לקו ה-dev דורש התקנה ידנית אחת של בילד dev; לאחר מכן ערוץ Dev מעדכן אותו קדימה.

התקנת Beta עוברת לגרסה הסופית על ידי מעבר ל-Release, שבו הגרסה היציבה מדורגת מעל המועמדים שלה.

## צעדים הבאים

- [ערוצי עדכון](/vibe/docs#update-channels) לקובצי הערוצים ולכללי התגים.
- [למה ערוצי העדכון עובדים כך](/vibe/docs#update-channels-design) לסדר הגרסאות.
