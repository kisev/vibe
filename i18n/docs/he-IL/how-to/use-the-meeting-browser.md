# שימוש בדפדפן הפגישות

Vibe יכול לארח שיחה בחלון משלו עם סרגל שנשאר תמיד מעל, שפעולתו הראשית היא **הקלטת השיחה**. החלון משתמש ב-webview של הפלטפורמה; [למה דפדפן הפגישות עובד כך](/vibe/docs#meeting-browser) מכסה את הבידוד ואת המגבלות.

## פתיחת שיחה ב-Vibe

השתמשו באחד מהנתיבים האלה:

- פתחו את **הגדרות → הקלטה → פתיחה ב-Vibe**, הדביקו את הקישור ופתחו אותו.
- מאפליקציה אחרת, סקריפט או קיצור דרך, קראו ל-`vibe://open/?url=https://…`. Vibe מקבל רק כתובות https תקינות ומסרב לכל דבר אחר עם דיאלוג.
- הפעילו את **פתיחת קישורי פגישות ב-Vibe** תחת **הגדרות → הקלטה** כדי לרשום קישורי Zoom, Teams ו-Webex. זה זמין ב-Windows וב-Linux, לא ב-macOS.

לחיצה על קישור https ב-Chrome, Edge או Firefox עדיין פותחת את הדפדפן הזה. Vibe לא נרשם כדפדפן ברירת מחדל.

## קבלת סרגל ההקלטה

**הגדרות → הקלטה → מארחי פגישות** מפרט את המארחים שמקבלים את סרגל הפגישה. ברירות המחדל הן `telemost.yandex.ru` ו-`stream.wb.ru`.

- הוסיפו מארח כדי שהקישורים שלו יהפכו לסשנים ניתנים להקלטה.
- הסירו מארח כדי לאבד את הסרגל; הקישורים שלו עדיין נפתחים בחלון הדפדפן.

ההתאמה היא לפי שם מארח ב-https, כך ש-`sub.telemost.yandex.ru` תואם רשומת `telemost.yandex.ru` ואילו כתובת `http` לא. הרשימה היא מסנן נוח, לא גבול אבטחה: כל קישור https נפתח בחלון, אבל רק מארחים ברשימה מקבלים את הסרגל.

## הקלטת שיחה

1. פתחו את הפגישה ב-Vibe.
1. לחצו על **הקלטת השיחה** לפני השיחה או במהלכה.
1. עצרו מהסרגל או מהחלון הראשי.

ההקלטה ידנית; חלון פגישה אף פעם לא מתחיל הקלטה מעצמו. המקליט לוכד את המיקרופון שהוגדר, וכשהוא מופעל, גם את לופ־הבק של שמע המערכת, כך ששני הצדדים של השיחה מוקלטים.

סגירת החלון בזמן הקלטה שואלת אם לעצור או להמשיך להקליט ברקע.

## נפילה חזרה לדפדפן המערכת

אם שירות מסרב לרוץ ב-webview המוטמע, השתמשו ב-**פתיחה בדפדפן המערכת** בסרגל. זו הנפילה החזרה הנתמכת לאתרים עתירי DRM או עוינים ל-WebRTC.

## צעדים הבאים

- [למה דפדפן הפגישות עובד כך](/vibe/docs#meeting-browser) מסביר את סכימת ה-URL, את ה-webview המבודד ואת כלל ההקלטה הידנית.
- [הקלטת מיקרופון ושמע מערכת](/vibe/docs#record-audio) מכסה הקלטה מחוץ לשיחה.
