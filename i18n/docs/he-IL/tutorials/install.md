# התקנת Vibe

מדריך זה מוביל ממחשב חדש, מהורדה ועד חלון Vibe פועל. הוא מניח שולחן עבודה עם חיבור לאינטרנט וללא התקנה קיימת. [תמלול ההקלטה הראשונה שלכם](/vibe/docs#first-transcription) הוא הצעד הבא.

## הורדת קובץ ההתקנה

פתחו את [דף ההורדה](https://kisev.github.io/vibe/) ובחרו את הבילד למחשב הזה:

| פלטפורמה | בילד |
| --- | --- |
| Windows | קובץ התקנה `.exe` |
| macOS, Apple silicon | `aarch64.dmg` |
| macOS, Intel | `x64.dmg` |
| Linux | `.deb` או `.rpm`, x86-64 או arm64 |

אותם קבצים מצורפים לכל [גרסת GitHub](https://github.com/kisev/vibe/releases). קובץ ה-`.deb` של Linux מצהיר על תלויות הריצה שלו, כולל `ffmpeg`.

## התקנה ופתיחה

1. הריצו את קובץ ההתקנה ופעלו לפי ההנחיות שלו.
1. פתחו את Vibe מתפריט האפליקציות, או הריצו `vibe` ממסוף.

בילדי השחרור אינם חתומים. ב-macOS ההפעלה הראשונה דורשת לחיצה ימנית → **פתיחה** ב-Finder כדי לעבור את Gatekeeper; הפעלות מאוחרות יותר נפתחות כרגיל. Windows SmartScreen עשוי להציג אזהרה מאותה סיבה.

## סיום ההגדרה

בהפעלה הראשונה Vibe מציע את מודל ברירת המחדל. אשרו את ההורדה והמתינו לסיומה. המודל נשמר מקומית ומשמש בכל הפעלה מאוחרת; [מודלים](/vibe/docs#models) מפרט את החלופות.

החלון מוכן כאשר אזור ההשלכה והפעולות **הקלטה** ו**מקישור** גלויים.

## צעדים הבאים

- [תמלול ההקלטה הראשונה שלכם](/vibe/docs#first-transcription) משתמש בהתקנה הזו.
- [פורמטים נתמכים](/vibe/docs#formats) מפרט מה Vibe יכול לפתוח ולייצא.
- [פתרון בעיות בקריסה](https://github.com/kisev/vibe/blob/main/docs/how-to/troubleshoot-a-crash.md) מכסה לוגים ואבחון אם החלון לא נפתח.
