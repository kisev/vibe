# הגדרות ותצורה

ההגדרות נמצאות ב-`app_config.json` בתיקיית הגדרות האפליקציה. הקובץ מיועד לקריאה ולעריכה: Vibe עוקב אחריו ומחיל שינוי חיצוני בלי הפעלה מחדש. **הגדרות → סוכנים → קובץ הגדרות** פותח אותו.

## מיקום קובץ ההגדרות

| פלטפורמה | תיקייה |
| --- | --- |
| macOS | `~/Library/Application Support/github.com.thewh1teagle.vibe` |
| Windows | `%appdata%\github.com.thewh1teagle.vibe` |
| Linux | `~/.config/github.com.thewh1teagle.vibe` |

התיקייה שומרת על המזהה של upstream, כך שהשם לא השתנה מבילדים קודמים.

## מדורי ההגדרות

| מדור | מכיל |
| --- | --- |
| כללי | שפת תצוגה, ערכת נושא, עדכונים, המשך פעולה במגש המערכת, הפעלה אוטומטית בהתחברות, מניעת מעבר המחשב למצב שינה |
| פרטיות | אם פרויקטים נשמרים, ומדיניות הפרטיות |
| תמלול | שפה, ייצוא אוטומטי, צליל ומיקוד בסיום, תיקיית פרויקטים |
| מודלים | בחירת CPU/GPU, התקן GPU, קטלוג מודלים, מודל זיהוי דוברים |
| כוונון | אפשרויות Whisper, עיבוד אודיו, זיכרון מודל וזמן פריקה |
| הקלטה | דפדפן פגישות, זיהוי פגישות, תמלול אוטומטי, קיצור הקלטה, הרשאות ב-macOS |
| הכתבה | קיצור הכתבה ומצב הפעלה |
| AI | סיכומים ומשימות הכתבה, חיבור לפלטפורמה |
| טלפון | העברה מהטלפון, חיבור, מכשירים מחוברים |
| סוכנים | API מקומי, מיומנות סוכנים, קובץ הגדרות |
| מתקדם | לוגים, אבחון ובקרות מפתחים |

## ערכים שכדאי להכיר

| קבוצת מפתחות | משמעות |
| --- | --- |
| `transcription.*` | שפה, פרומפט, זיהוי דוברים, חותמות זמן, פיצול הקלטות ארוכות |
| `model.*` | מודל נבחר, שמות תצוגה, התקן GPU, מתג CPU בלבד, זמן פריקה |
| `transcript.*` | פורמט ייצוא, חותמות זמן, דוברים, ייצוא אוטומטי |
| `recording.*` | התקני קלט ופלט, זיהוי פגישות, קיצור הקלטה |
| `ai.*` | פלטפורמה, כתובת בסיס, מפתח, מודל, פרומפט ומתגים לכל משימה |
| `general.updateChannel` | `stable`, `beta` או `dev` |
| `handoff.pairing` | התקני טלפון מחוברים וגיבובי אישורים |

שמות השדות המדויקים יציבים מספיק לעריכה, אבל האפליקציה היא הבעלים של הסכימה: שנו ערך דרך ממשק ההגדרות כשהוא קיים, ותנו לאפליקציה לכתוב את הקובץ מחדש במקום להחליף אותו כולו.
