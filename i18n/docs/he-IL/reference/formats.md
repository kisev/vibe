# פורמטים נתמכים

Vibe מקבל קבצי אודיו ווידאו ומייצא תמלולים בכמה פורמטי טקסט. אפליקציית השולחן מנרמלת מדיה עם ffmpeg לפני התמלול; ב-Linux נדרש `ffmpeg` של המערכת, בעוד שב-macOS וב-Windows החבילות מגיעות עם ffmpeg משלהן.

## קלט

| סוג | סיומות |
| --- | --- |
| אודיו | `mp3`, `wav`, `aac`, `flac`, `oga`, `ogg`, `opus`, `m4a`, `m4b`, `wma` |
| וידאו | `mp4`, `mkv`, `avi`, `mov`, `wmv`, `webm`, `mxf` |

מכל שאינו ברשימה הזו עשוי עדיין לעבוד אם ffmpeg יכול לפענח אותו; המירו אותו קודם אם האפליקציה מסרבת לו.

## ייצוא בשולחן העבודה

פתחו את חלון הייצוא על תמלול ובחרו אחד מאלה:

| פורמט | תוכן |
| --- | --- |
| TXT | טקסט פשוט ללא עיצוב |
| Markdown | כותרות וטקסט מעוצב |
| SRT | כתוביות ממוספרות עם חותמות זמן |
| VTT | כתוביות WebVTT עם חותמות זמן |
| HTML | דף אינטרנט מעוצב |
| JSON | נתוני תמלול ותזמון מובנים |
| CSV | שורות מוכנות לגיליון אלקטרוני |
| DOCX | מסמך Word מעוצב |
| PDF | מסמך מוכן להדפסה |

אפשרויות הייצוא גם מדליקות ומכבות חותמות זמן ותוויות דוברים כאשר הפורמט תומך בהם. ייצוא אוטומטי יכול לכתוב כל אחד מהפורמטים האלה ליד ההקלטה, לתיקיית הפרויקטים, או לתיקייה שתבחרו.

## פלט שורת פקודה

`vibe-server transcribe` כותב `txt` (ברירת מחדל), `markdown` (כינוי `md`), `json`, `srt` או `vtt`. `--output` כותב קובץ חדש ומסרב לדרוס נתיב קיים. ראו [שורת פקודה](/vibe/docs#cli).
