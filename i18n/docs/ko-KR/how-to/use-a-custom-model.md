# 사용자 지정 모델 가져오기

Vibe는 번들 엔진을 통해 GGUF 모델을 실행합니다. **설정 → 모델**의 카탈로그는 테스트된 모델군을 다루며, 이 가이드는 카탈로그에 없는 모델 하나를 추가합니다. [모델](/vibe/docs#models)은 각 모델군이 지원하는 기능의 레퍼런스입니다.

## URL에서 다운로드

1. **설정 → 모델**을 엽니다.
1. **모델 다운로드**에 직접 모델 링크를 붙여넣고 확인합니다.
1. 다운로드가 끝날 때까지 기다립니다. 파일은 모델 폴더에 저장됩니다.
1. 모델 목록에서 새 모델을 선택합니다.

Vibe는 같은 요청을 딥 링크로도 받아들입니다:

```text
vibe://download/?url=https://example.com/model.gguf
```

붙여넣은 URL에는 크기나 체크섬이 없으므로 Vibe는 파일을 수락하기 전에 다운로드한 바이트와 GGUF/BIN 헤더를 확인합니다. [모델](/vibe/docs#models)의 카탈로그 항목에는 고정된 리비전, 크기, SHA-256이 있습니다.

## 디스크의 파일 사용

1. `.gguf` 파일을 모델 폴더에 넣습니다. 폴더 경로는 **설정 → 모델 → 모델 폴더**에 있으며, 여기서 폴더를 열 수도 있습니다.
1. **설정 → 모델**로 돌아가면 파일이 설치된 목록에 나타납니다.
1. 파일을 선택합니다.

**모델 폴더 변경**을 통해서만 폴더를 옮기거나 이름을 바꾼 다음 모델을 다시 선택하세요.

## 모델이 로드되지 않을 때

- 파일은 GGUF이거나 엔진이 받아들이는 레거시 `.bin` 컨테이너여야 합니다.
- 번들된 것보다 최신 transcribe.cpp가 필요한 모델은 카탈로그에 표시되지만 아직 로드할 수 없습니다.
- 고정 언어 모델은 다른 언어를 거부하며, 오류에 지원 언어가 표시됩니다.

## 다음 단계

- 테스트된 카탈로그와 모델군별 제한은 [모델](/vibe/docs#models).
- 창 없이 모델을 실행하려면 [명령줄](/vibe/docs#cli).
