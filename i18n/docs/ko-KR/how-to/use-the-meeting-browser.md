# 회의 브라우저 사용

Vibe는 자체 창에서 통화를 호스팅할 수 있으며, 항상 위에 표시되는 표시줄의 주 동작은 **이 회의 녹음**입니다. 창은 플랫폼 웹뷰를 사용합니다. [회의 브라우저가 이렇게 동작하는 이유](/vibe/docs#meeting-browser)는 격리와 제한을 다룹니다.

## Vibe에서 통화 열기

다음 경로 중 하나를 사용합니다:

- **설정 → 녹음 → Vibe에서 열기**를 열고 링크를 붙여넣은 다음 엽니다.
- 다른 앱, 스크립트, 단축키에서 `vibe://open/?url=https://…`를 호출합니다. Vibe는 올바른 형식의 https URL만 받아들이고 나머지는 대화상자로 거부합니다.
- **설정 → 녹음**에서 **Vibe에서 회의 링크 열기**를 켜 Zoom, Teams, Webex 링크를 등록합니다. 이 기능은 macOS가 아니라 Windows와 Linux에서 사용할 수 있습니다.

Chrome, Edge, Firefox에서 https 링크를 클릭하면 여전히 그 브라우저가 열립니다. Vibe는 기본 브라우저로 등록되지 않습니다.

## 녹음 표시줄 표시

**설정 → 녹음 → 회의 호스트**는 회의 표시줄이 표시되는 호스트를 나열합니다. 기본값은 `telemost.yandex.ru`와 `stream.wb.ru`입니다.

- 호스트를 추가하면 그 링크가 녹음 가능한 세션이 됩니다.
- 호스트를 제거하면 표시줄이 사라집니다. 그 링크는 여전히 브라우저 창에서 열립니다.

일치는 https를 통한 호스트 이름으로 이루어지므로 `sub.telemost.yandex.ru`는 `telemost.yandex.ru` 항목과 일치하지만 `http` URL은 일치하지 않습니다. 이 목록은 편의 필터일 뿐 보안 경계가 아닙니다. 모든 https 링크는 창에서 열리지만, 나열된 호스트만 표시줄을 받습니다.

## 통화 녹음

1. Vibe에서 회의를 엽니다.
1. 통화 전이나 도중에 **이 회의 녹음**을 누릅니다.
1. 표시줄이나 메인 창에서 중지합니다.

녹음은 수동입니다. 회의 창은 스스로 녹음을 시작하지 않습니다. 녹음기는 구성된 마이크와, 활성화된 경우 시스템 오디오 루프백을 캡처하므로 통화 양쪽이 녹음됩니다.

녹음 중에 창을 닫으면 중지할지 백그라운드에서 계속 녹음할지 묻습니다.

## 시스템 브라우저로 대체

서비스가 삽입된 웹뷰에서 실행되기를 거부하면 표시줄의 **시스템 브라우저에서 열기**를 사용합니다. DRM이 많거나 WebRTC를 싫어하는 사이트에 지원되는 대체 경로입니다.
