# 회의 브라우저 사용

Vibe는 자체 Chromium 기반 창에서 통화를 호스팅할 수 있습니다. 앱의 표시줄(주소, 뒤로, 앞으로, 새로고침, 외부 열기, 닫기, **이 회의 녹음**)이 창 상단에 있고 페이지가 같은 창의 나머지를 채웁니다. 별도의 표시줄 창은 없습니다. URL 스킴과 허용 목록은 [회의 브라우저 참조](../reference/meeting-browser.md)를, 이 메커니즘이 이렇게 동작하는 이유는 [설명](../explanation/meeting-browser.md)을 참조하세요.

## Vibe에서 통화 열기

다음 경로 중 하나를 사용합니다:

- 다른 앱이나 시스템에서: **설정 → 녹음**에서 **Vibe에서 회의 링크 열기**를 켜면 Zoom, Teams, Webex 링크가 등록됩니다(Windows와 Linux, macOS 제외). 앱은 매핑된 URL을 검증하고, 호스트를 로드할 수 있으면 브라우저 창에서, 아니면 시스템 브라우저에서 엽니다.
- Vibe 안에서: 홈 페이지의 **회의 브라우저** 소스 또는 **설정 → 녹음 → Vibe에서 열기**를 사용하고, 링크를 붙여넣은 다음 **Vibe에서 열기**를 누릅니다.
- 링크의 호스트는 허용 목록에 있어야 합니다. 목록 밖의 최상위 탐색과 교차 출처 리소스는 거부됩니다. 표시줄의 녹음 제어는 허용된 모든 페이지에 있습니다.

Chrome, Edge, Firefox에서 https 링크를 클릭하면 여전히 그 브라우저가 열립니다. Vibe는 기본 브라우저로 등록되지 않습니다.

## 통화 녹음

1. Vibe에서 회의를 엽니다.
1. 통화 전이나 도중에 창의 표시줄에서 **이 회의 녹음**을 누릅니다.
1. 표시줄이나 메인 창에서 중지합니다.

녹음은 수동입니다. 회의 창은 스스로 녹음을 시작하지 않습니다. 녹음기는 구성된 마이크와, 활성화된 경우 시스템 오디오 루프백을 캡처하므로 통화 양쪽이 녹음됩니다.

표시줄의 마이크 및 스피커 선택기는 메인 창이 사용하는 것과 같은 장치를 변경하므로, 통화를 떠나지 않고 오디오 경로를 바꿀 수 있습니다. 녹음이 실행되는 동안에는 비활성화되며 캡처 중인 장치의 이름을 표시합니다. 해당 녹음에서 캡처하지 않는 소스는 **없음**으로 표시됩니다.

녹음 중에 창을 닫으면 중지할지 백그라운드에서 계속 녹음할지 묻습니다.

## 사용하는 사이트 허용

**설정 → 녹음 → 허용된 도메인**은 브라우저의 허용 목록입니다. 처음에는 비어 있습니다. 필요한 도메인을 하나씩 추가하면 해당 하위 도메인도 https를 통해 포함됩니다.

목록에 있는 도메인만 로드될 수 있습니다. 다른 호스트로 가는 링크는 거부되며, 허용된 페이지가 목록에 없는 오리진에서 가져오는 스크립트, 글꼴, 이미지도 마찬가지로 거부됩니다. 거부된 호스트는 **차단됨** 아래에 도메인을 추가하고 페이지를 다시 로드하는 **허용** 동작과 함께 표시됩니다. 표시줄은 탐색을 거부할 때도 같은 제안을 표시합니다.

엄격한 목록은 자산을 CDN에서 가져오는 페이지를 해당 CDN이 허용될 때까지 깨뜨릴 수 있습니다. 그것이 의도된 절충이며, 차단됨 목록 덕분에 수정은 클릭 한 번입니다.

## 시스템 브라우저로 대체

서비스가 삽입된 웹뷰에서 실행되기를 거부하면 표시줄의 **시스템 브라우저에서 열기**를 사용합니다. 시스템 브라우저는 DRM이 많거나 WebRTC를 싫어하는 사이트에 지원되는 대체 경로입니다.

macOS에서는 삽입된 브라우저에 창 내 표시줄이 없습니다. 페이지는 페이지 전용 창에서 열리고, 녹음은 메인 창에서 계속 사용할 수 있으며, 시스템 브라우저가 통화 전체의 대체 경로입니다.
