# 업데이트 채널 전환

Vibe는 릴리스, 베타, Dev 세 가지 업데이트 채널 중 하나를 확인합니다. 채널은 앱이 제공하는 빌드를 결정하며, 항상 앞으로만 이동합니다.

## 채널 선택

1. **설정 → 일반 → 업데이트**를 엽니다.
1. **릴리스**, **베타**, **Dev** 중 하나를 고릅니다.
1. **업데이트 확인**을 누릅니다.

같은 섹션에 설치된 버전, 마지막 확인 시간, 결과가 표시됩니다. 확인은 시작 시에도 실행됩니다.

## 각 채널이 제공하는 빌드

| 채널 | 빌드 |
| --- | --- |
| 릴리스 | 안정 버전 |
| 베타 | 다음 안정 버전의 출시 후보 |
| Dev | 최신 `dev` 빌드 |

Dev를 선택한 릴리스 또는 베타 설치에서는 **최신 상태**가 표시됩니다. 모든 dev 빌드는 이미 실행 중인 버전보다 아래로 정렬되기 때문입니다. dev 라인으로 이동하려면 dev 빌드를 한 번 직접 설치해야 하며, 그 이후에는 Dev 채널이 앞으로 업데이트합니다.

베타 설치는 릴리스로 전환하면 최종 릴리스로 이동합니다. 안정 버전이 출시 후보보다 위로 정렬되기 때문입니다.
