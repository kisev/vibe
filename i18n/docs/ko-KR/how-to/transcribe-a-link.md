# 링크에서 받아쓰기

Vibe는 미디어 URL 뒤의 오디오를 yt-dlp로 다운로드해 받아씁니다. 지원되는 사이트는 yt-dlp가 지원하는 사이트이며, 사이트가 작동을 멈추면 보통 yt-dlp를 업데이트하면 해결됩니다.

## 링크 보내기

1. Vibe를 열고 **링크에서**를 선택합니다.
1. URL 하나를 붙여넣거나, 공백으로 구분해 여러 개를 붙여넣어 모두 대기열에 넣습니다.
1. **받아쓰기**를 누릅니다.

Vibe는 링크를 처음 사용할 때 yt-dlp 설치를 묻고, 사이트가 실패하면 업데이트를 묻습니다. 다운로드한 오디오는 임시이며, 전사는 다른 프로젝트처럼 저장됩니다.

## 예상할 수 있는 동작

- 링크 하나는 다운로드가 끝나는 즉시 시작됩니다.
- 대기열은 링크를 한 번에 하나씩 실행하고 항목별 진행률을 표시합니다.
- 가중치, 모델, 전사는 로컬에 남습니다. 다운로드 자체는 미디어 호스트와 yt-dlp용 GitHub에 접속합니다.
