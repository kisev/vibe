# 전사 요약

Vibe는 완료된 전사를 요약, 노트 또는 번역으로 바꿀 수 있습니다. 요청은 구성한 AI 플랫폼으로 전달됩니다: 로컬 Ollama 모델, Claude, 또는 OpenAI 호환 엔드포인트. [설정 및 구성](/vibe/docs#settings)은 연결이 저장되는 위치를 나열합니다.

## 로컬 Ollama 모델 사용

1. [Ollama](https://ollama.com)를 설치하고 모델을 받습니다. 예: `ollama pull llama3.1`.
1. **설정 → AI**를 엽니다.
1. **플랫폼**을 **Ollama**로 설정합니다. 기본 URL은 `http://localhost:11434`입니다.
1. 모델 이름을 고릅니다.
1. **요약**을 켜고, 선택적으로 **새 전사를 자동으로 요약**을 켭니다.

Ollama는 이 컴퓨터에서 실행되므로 전사가 로컬에 남습니다.

## Claude 또는 OpenAI 호환 엔드포인트 사용

1. **설정 → AI**를 열고 플랫폼을 고릅니다.
1. API 키를 붙여넣고, 엔드포인트가 기본값이 아니면 기본 URL을 변경합니다.
1. 모델을 고릅니다.
1. **요약**을 켭니다.

기본값이 아닌 엔드포인트의 경우 기본 URL과 키가 앱이 요약과 받아쓰기 모두에 사용하는 연결입니다.

## 요약

1. 받아쓰기를 완료합니다.
1. 전사 보기에서 요약 기능을 엽니다.
1. 프리셋을 고르고 필요하면 프롬프트를 편집합니다.
1. 실행합니다. 결과는 프로젝트와 함께 저장되며 전사 옆으로 내보낼 수 있습니다.

**새 전사를 자동으로 요약**이 활성화되어 있으면 받아쓰기가 완료되는 즉시 요약이 실행됩니다.
