# 지원되는 형식

Vibe는 오디오 및 비디오 파일을 받아들이고 전사를 여러 텍스트 형식으로 내보냅니다. 데스크톱 앱은 받아쓰기 전에 ffmpeg로 미디어를 정규화합니다. Linux에서는 시스템 `ffmpeg`가 필요하고, macOS와 Windows 번들에는 자체 ffmpeg가 포함됩니다.

## 입력

| 종류 | 확장자 |
| --- | --- |
| 오디오 | `mp3`, `wav`, `aac`, `flac`, `oga`, `ogg`, `opus`, `m4a`, `m4b`, `wma` |
| 비디오 | `mp4`, `mkv`, `avi`, `mov`, `wmv`, `webm`, `mxf` |

이 목록에 없는 컨테이너도 ffmpeg가 디코딩할 수 있으면 작동할 수 있습니다. 앱이 거부하면 먼저 변환하세요.

## 데스크톱 내보내기

전사에서 내보내기 대화상자를 열고 다음 중 하나를 고릅니다:

| 형식 | 내용 |
| --- | --- |
| TXT | 서식 없는 일반 텍스트 |
| Markdown | 제목과 서식이 포함된 Markdown |
| SRT | 번호가 매겨진 타임스탬프가 포함된 자막 |
| VTT | 타임스탬프가 포함된 웹 자막 |
| HTML | 스타일이 적용된 웹페이지 |
| JSON | 구조화된 전사 및 시간 데이터 |
| CSV | 스프레드시트에서 바로 사용할 수 있는 행 |
| DOCX | 서식이 적용된 Word 문서 |
| PDF | 인쇄 가능한 문서 |

내보내기 옵션은 형식이 지원하는 경우 타임스탬프와 화자 레이블도 전환합니다. 자동 내보내기는 이러한 형식을 녹음 옆, 프로젝트 폴더 또는 직접 선택한 폴더에 쓸 수 있습니다.

## CLI 출력

`vibe-server transcribe`는 `txt`(기본값), `markdown`(별칭 `md`), `json`, `srt`, `vtt`를 씁니다. `--output`은 새 파일을 쓰며 기존 경로 덮어쓰기를 거부합니다. [명령줄](/vibe/docs#cli)을 참고하세요.
