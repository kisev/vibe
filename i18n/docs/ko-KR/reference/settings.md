# 설정 및 구성

설정은 앱 설정 디렉터리의 `app_config.json`에 있습니다. 이 파일은 읽고 편집하기 위한 것입니다. Vibe는 파일을 감시하고 외부 변경을 재시작 없이 적용합니다. **설정 → 에이전트 → 설정 파일**에서 엽니다.

## 설정 파일 위치

| 플랫폼 | 디렉터리 |
| --- | --- |
| macOS | `~/Library/Application Support/github.com.thewh1teagle.vibe` |
| Windows | `%appdata%\github.com.thewh1teagle.vibe` |
| Linux | `~/.config/github.com.thewh1teagle.vibe` |

디렉터리는 업스트림 식별자를 유지하므로 이전 빌드와 이름이 같습니다.

## 설정 섹션

| 섹션 | 포함 내용 |
| --- | --- |
| 일반 | 표시 언어, 테마, 업데이트, 트레이에서 계속 실행, 시작 시 자동 실행, 절전 방지 |
| 개인정보 | 프로젝트 저장 여부, 개인정보 처리방침 |
| 트랜스크립션 | 언어, 자동 내보내기, 완료 시 소리와 창 포커스, 프로젝트 폴더 |
| 모델 | CPU/GPU 선택, GPU 장치, 모델 카탈로그, 화자 분리 모델 |
| 세부 조정 | Whisper 옵션, 오디오 처리, 모델 메모리와 언로드 타임아웃 |
| 녹음 | 회의 브라우저, 회의 감지, 자동 받아쓰기, 녹음 단축키, macOS 권한 |
| 받아쓰기 | 받아쓰기 단축키와 활성화 모드 |
| AI | 요약과 받아쓰기 작업, 플랫폼 연결 |
| 휴대폰 | 휴대폰 연동, 페어링, 페어링된 기기 |
| 에이전트 | 로컬 API, 에이전트 스킬, 설정 파일 |
| 고급 | 로그, 진단, 개발자 제어 |

## 알아 둘 값

| 키 그룹 | 의미 |
| --- | --- |
| `transcription.*` | 언어, 프롬프트, 화자 분리, 타임스탬프, 긴 녹음 분할 |
| `model.*` | 선택한 모델, 표시 이름, GPU 장치, CPU 전용 전환, 언로드 타임아웃 |
| `transcript.*` | 내보내기 형식, 타임스탬프, 화자, 자동 내보내기 |
| `recording.*` | 입력 및 출력 장치, 회의 감지, 녹음 단축키 |
| `ai.*` | 플랫폼, 기본 URL, 키, 모델, 작업별 프롬프트와 전환 |
| `general.updateChannel` | `stable`, `beta` 또는 `dev` |
| `handoff.pairing` | 페어링된 휴대폰 기기와 자격 증명 해시 |

정확한 필드 이름은 편집할 수 있을 만큼 안정적이지만 스키마는 앱이 소유합니다. 설정 UI가 있는 값은 UI에서 변경하고, 파일을 통째로 바꾸지 말고 앱이 파일을 다시 쓰게 하세요.
