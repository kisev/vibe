# Transcrire depuis votre téléphone

Vibe peut enregistrer sur un téléphone et transcrire sur cet ordinateur. Le téléphone ouvre une petite application web après avoir scanné un code ; rien ne s’installe depuis une boutique d’applications. Gardez Vibe ouvert pendant l’enregistrement.

## Activer le transfert

1. Ouvrez **Paramètres → Téléphone**.
1. Activez **Autoriser les enregistrements depuis le téléphone**.
1. Choisissez **Associer un téléphone**, puis **Afficher le code**.

## Associer le téléphone

1. Dirigez la caméra du téléphone vers le code QR.
1. Ouvrez la page qu’il propose et gardez-la ouverte.
1. L’appareil apparaît sous **Appareils associés** une fois l’association terminée.

L’association survit aux redémarrages de l’application et du navigateur du téléphone. Chaque profil de navigateur est un appareil distinct.

## Enregistrer et transcrire

1. Enregistrez sur la page du téléphone.
1. L’audio passe par le relais en étant chiffré de bout en bout ; cet ordinateur le reçoit, le transcrit et renvoie la transcription.
1. La transcription arrive aussi dans Récents sur l’ordinateur.

## Gérer les appareils

- **Révoquer** bloque cet appareil et interrompt un transfert actif.
- **Créer un nouveau code** remplace l’invitation. Les téléphones déjà associés gardent l’accès.
- **Tout révoquer** oblige chaque téléphone à scanner un nouveau code.
