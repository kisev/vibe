# 使用會議瀏覽器

Vibe 可以在自己的視窗中承載通話，並提供置頂工具列，其主要操作是**錄製此會議**。此視窗使用平台的 webview；[會議瀏覽器為何如此運作](/vibe/docs#meeting-browser)涵蓋隔離機制和限制。

## 在 Vibe 中開啟通話

使用以下其中一種方式：

- 開啟**設定 → 錄音 → 在 Vibe 中開啟**，貼上連結並開啟。
- 從其他應用程式、指令稿或捷徑呼叫 `vibe://open/?url=https://…`。Vibe 只接受格式正確的 https URL，其他一律以對話方塊拒絕。
- 在**設定 → 錄音**下開啟**在 Vibe 中開啟會議連結**，以註冊 Zoom、Teams 和 Webex 連結。此功能適用於 Windows 和 Linux，不適用於 macOS。

在 Chrome、Edge 或 Firefox 中點擊 https 連結仍然會開啟該瀏覽器。Vibe 不會註冊為預設瀏覽器。

## 取得錄音工具列

**設定 → 錄音 → 會議主機**列出了會取得會議工具列的主機。預設為 `telemost.yandex.ru` 和 `stream.wb.ru`。

- 新增主機，令其連結成為可錄製的會議。
- 移除主機以失去工具列；其連結仍會在瀏覽器視窗中開啟。

比對是透過 https 上的主機名稱進行，因此 `sub.telemost.yandex.ru` 會符合 `telemost.yandex.ru` 項目，而 `http` URL 則不符合。此清單是方便使用的篩選器，不是安全邊界：每個 https 連結都會在視窗中開啟，但只有列出的主機會取得工具列。

## 錄製通話

1. 在 Vibe 中開啟會議。
1. 在通話前或通話期間按**錄製此會議**。
1. 從工具列或主視窗停止。

錄音是手動的；會議視窗絕不會自行開始錄音。錄音器會擷取已設定的麥克風，以及在啟用時的系統音頻回送，因此通話雙方的聲音都會被錄下。

錄音期間關閉視窗時，會詢問要停止還是繼續在背景錄音。

## 退回系統瀏覽器

如果某項服務拒絕在內嵌 webview 中執行，請使用工具列中的**在系統瀏覽器中開啟**。這是針對大量使用 DRM 或對 WebRTC 不友善的網站所支援的退回方式。
