# 使用會議瀏覽器

Vibe 可以在自己的 Chromium 視窗中承載通話：應用程式的瀏覽器介面（網址、上一頁、下一頁、重新載入、在外部開啟、關閉，以及**錄製此會議**）位於頂部，頁面則填滿同一視窗的其餘部分。並沒有另一個獨立的橫條視窗。URL scheme 和允許清單見[會議瀏覽器參考](../reference/meeting-browser.md)，機制為何如此運作見[說明](../explanation/meeting-browser.md)。

## 在 Vibe 中開啟通話

使用以下其中一種方式：

- 從其他應用程式或系統：在**設定 → 錄音**下開啟**在 Vibe 中開啟會議連結**，以註冊 Zoom、Teams 和 Webex 連結（Windows 和 Linux，不適用於 macOS）。應用程式會驗證對應的 URL，並在主機允許載入時於瀏覽器視窗中開啟，否則交給系統瀏覽器。
- 在 Vibe 內：首頁的**會議瀏覽器**來源，或**設定 → 錄音 → 在 Vibe 中開啟**；貼上連結並按**在 Vibe 中開啟**。
- 連結的主機必須在允許清單中；清單以外的頂層瀏覽和跨來源資源會被拒絕。瀏覽器介面的錄音控制會出現在每個已允許的頁面上。

在 Chrome、Edge 或 Firefox 中點擊 https 連結仍然會開啟該瀏覽器。Vibe 不會註冊為預設瀏覽器。

## 錄製通話

1. 在 Vibe 中開啟會議。
1. 在通話前或通話期間，在視窗的瀏覽器介面中按**錄製此會議**。
1. 從瀏覽器介面或主視窗停止。

錄音是手動的；會議視窗絕不會自行開始錄音。錄音器會擷取已設定的麥克風，以及在啟用時的系統音頻回送，因此通話雙方的聲音都會被錄下。

瀏覽器介面中的麥克風和揚聲器選擇器會變更主視窗所用的相同裝置，因此無需離開通話便可調整其路由。錄音進行期間，它們會被停用，並顯示目前正在擷取的裝置；該次錄音未擷取的來源會顯示**無記錄**。

錄音期間關閉視窗時，會詢問要停止還是繼續在背景錄音。

## 允許你使用的網站

**設定 → 錄音 → 允許的網域**是瀏覽器的允許清單；它一開始是空的。加入每個你需要的網域，其子網域會透過 https 一併包含在內。

只有已列出的網域可以載入。指向其他主機的連結會被拒絕，已允許的頁面從未列出的來源取得的任何指令稿、字型或影像也一樣。被拒絕的主機會顯示在**已封鎖**下，並附有**允許**操作，會加入該網域並重新載入頁面。瀏覽器介面在拒絕瀏覽時也會顯示相同的選項。

嚴格的清單可能會令資源來自 CDN 的頁面在允許該 CDN 之前無法運作；這是預期的取捨，而「已封鎖」清單讓修復只需按一下。

## 退回系統瀏覽器

如果某項服務拒絕在內嵌 webview 中執行，請使用瀏覽器介面中的**在系統瀏覽器中開啟**。系統瀏覽器是針對大量使用 DRM 或對 WebRTC 不友善的網站所支援的退回方式。

在 macOS 上，內嵌瀏覽器沒有視窗內的瀏覽器介面：頁面會在純頁面視窗中開啟，錄音仍可從主視窗使用，而系統瀏覽器則是整通通話的退回方式。
