# 從連結轉錄

Vibe 會使用 yt-dlp 下載媒體 URL 背後的音頻，並轉錄結果。支援的網站就是 yt-dlp 支援的網站；當某個網站停止運作時，更新 yt-dlp 通常可以修復。

## 傳送連結

1. 開啟 Vibe 並選擇**從連結**。
1. 貼上一條 URL，或貼上以空白分隔的多條 URL，將它們全部加入佇列。
1. 按**開始轉錄**。

首次使用連結時，Vibe 會要求安裝 yt-dlp；當網站失效時，則會要求更新。下載的音頻是暫時性的；轉錄文字會像其他專案一樣儲存。

## 預期情況

- 單一連結會在下載完成後立即開始。
- 佇列會一次執行一條連結，並顯示每個項目的進度。
- 權重、模型和轉錄文字都留在本機。下載本身會聯絡媒體主機，以及 GitHub 上的 yt-dlp。
