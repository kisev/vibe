# 匯入自訂模型

Vibe 透過內建引擎執行 GGUF 模型。**設定 → 模型**中的目錄涵蓋已測試的模型家族；本指南會加入一個目錄未列出的模型。[模型](/vibe/docs#models)是每個家族支援內容的參考。

## 從 URL 下載

1. 開啟**設定 → 模型**。
1. 將直接模型連結貼到**下載模型**並確認。
1. 等待下載完成；檔案會放入模型資料夾。
1. 在模型清單中選取新模型。

Vibe 亦接受以深層連結提出相同請求：

```text
vibe://download/?url=https://example.com/model.gguf
```

貼上的 URL 不附帶大小或校驗碼，因此 Vibe 在接受檔案前會檢查已下載的位元組和 GGUF/BIN 標頭。[模型](/vibe/docs#models)中的目錄項目則附有固定修訂、大小和 SHA-256。

## 使用磁碟上的檔案

1. 將 `.gguf` 檔案放入模型資料夾。資料夾路徑位於**設定 → 模型 → 模型資料夾**，該處亦可開啟它。
1. 返回**設定 → 模型**；檔案會出現在已安裝清單中。
1. 選取它。

只可透過**更改模型資料夾**移動或重新命名資料夾，然後再次選取模型。

## 當模型無法載入時

- 檔案必須是 GGUF，或引擎接受之舊式 `.bin` 容器。
- 需要比內建版本更新之 transcribe.cpp 的模型會列於目錄中，但暫時無法載入。
- 語言固定的模型會拒絕其他語言；錯誤訊息會指出支援的語言。
