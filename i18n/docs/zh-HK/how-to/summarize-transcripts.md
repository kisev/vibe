# 總結轉錄文字

Vibe 可以將完成的轉錄文字變成摘要、筆記或翻譯。請求會傳送到你設定的 AI 平台：本機 Ollama 模型、Claude，或任何與 OpenAI 相容的端點。[設定與配置](/vibe/docs#settings)列出了連線的儲存位置。

## 使用本機 Ollama 模型

1. 安裝 [Ollama](https://ollama.com) 並下載一個模型，例如 `ollama pull llama3.1`。
1. 開啟**設定 → AI**。
1. 將**平台**設為 **Ollama**。預設 URL 是 `http://localhost:11434`。
1. 挑選模型名稱。
1. 開啟**摘要**，並可選擇**自動總結新的轉錄**。

Ollama 在這部電腦上執行，因此轉錄文字會留在本機。

## 使用 Claude 或與 OpenAI 相容的端點

1. 開啟**設定 → AI**並選擇平台。
1. 貼上 API 金鑰，若端點不是預設值，則更改基本 URL。
1. 挑選模型。
1. 開啟**摘要**。

對於非預設端點，基本 URL 和金鑰就是應用程式用於摘要和語音輸入的連線。

## 總結

1. 完成一次轉錄。
1. 在轉錄文字檢視中開啟摘要操作。
1. 挑選預設集，如有需要則編輯提示詞。
1. 執行它；結果會隨專案一併儲存，並可與轉錄文字一併匯出。

啟用**自動總結新的轉錄**後，轉錄一完成便會執行摘要。
