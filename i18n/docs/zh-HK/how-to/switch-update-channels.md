# 切換更新頻道

Vibe 會檢查三個更新頻道之一：正式版、Beta 或 Dev。頻道決定應用程式提供哪些構建版本，而且只會向前推進。

## 選擇頻道

1. 開啟**設定 → 一般 → 更新**。
1. 挑選**正式版**、**Beta** 或 **Dev**。
1. 按**檢查更新**。

同一區段會顯示已安裝版本、上次檢查時間和結果。檢查亦會在啟動時執行。

## 每個頻道包含什麼

| 頻道 | 構建版本 |
| --- | --- |
| 正式版 | 穩定版本 |
| Beta | 下一個穩定版本的發行候選版 |
| Dev | 最新的 `dev` 構建版本 |

選擇 Dev 的正式版或 Beta 安裝會看到**已是最新版本**：每個 dev 構建版本的排序都低於它已執行的版本。轉到 dev 版本線需要手動安裝一次 dev 構建版本；之後 Dev 頻道便會將其向前更新。

Beta 安裝可透過切換到正式版來移至最終發行版本，因為穩定版本的排序高於其候選版本。
