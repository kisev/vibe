# Поддерживаемые форматы

Vibe принимает аудио- и видеофайлы и экспортирует расшифровки в нескольких текстовых форматах. Настольное приложение перед транскрипцией нормализует медиа с помощью ffmpeg; в Linux требуется системный `ffmpeg`, а сборки для macOS и Windows включают его в себя.

## Входные данные

| Тип | Расширения |
| --- | --- |
| Аудио | `mp3`, `wav`, `aac`, `flac`, `oga`, `ogg`, `opus`, `m4a`, `m4b`, `wma` |
| Видео | `mp4`, `mkv`, `avi`, `mov`, `wmv`, `webm`, `mxf` |

Контейнер вне этого списка может всё равно подойти, если ffmpeg умеет его декодировать; сначала преобразуйте его, если приложение откажется.

## Экспорт в настольном приложении

Откройте диалог экспорта расшифровки и выберите один из вариантов:

| Формат | Содержимое |
| --- | --- |
| TXT | Обычный текст без форматирования |
| Markdown | Заголовки и форматированный текст |
| SRT | Пронумерованные субтитры с метками времени |
| VTT | Субтитры WebVTT с метками времени |
| HTML | Оформленная веб-страница |
| JSON | Структурированные данные расшифровки и времени |
| CSV | Строки, готовые для электронной таблицы |
| DOCX | Форматированный документ Word |
| PDF | Документ для печати |

Параметры экспорта также включают или выключают метки времени и метки говорящих там, где формат их поддерживает. Автоэкспорт может записывать любой из этих форматов рядом с записью, в папку проектов или в выбранную вами папку.

## Вывод CLI

`vibe-server transcribe` пишет `txt` (по умолчанию), `markdown` (псевдоним `md`), `json`, `srt` или `vtt`. `--output` записывает новый файл и отказывается перезаписывать существующий путь. См. [Командная строка](/vibe/docs#cli).
