# Настройки и конфигурация

Настройки хранятся в `app_config.json` в каталоге конфигурации приложения. Файл предназначен для чтения и редактирования: Vibe следит за ним и применяет внешнее изменение без перезапуска. Открыть его можно через **Настройки → Агенты → Файл конфигурации**.

## Расположение файла конфигурации

| Платформа | Каталог |
| --- | --- |
| macOS | `~/Library/Application Support/github.com.thewh1teagle.vibe` |
| Windows | `%appdata%\github.com.thewh1teagle.vibe` |
| Linux | `~/.config/github.com.thewh1teagle.vibe` |

Каталог сохраняет идентификатор из апстрима, поэтому имя не изменилось по сравнению с более ранними сборками.

## Разделы настроек

| Раздел | Содержит |
| --- | --- |
| Общие | Язык интерфейса, тема, обновления, работа в трее, запуск при входе в систему, запрет сна |
| Конфиденциальность | Сохраняются ли проекты, и политика конфиденциальности |
| Транскрипция | Язык, автоэкспорт, звук и фокус по завершении, папка проектов |
| Модели | Выбор CPU/GPU, устройство GPU, каталог моделей, модель разделения по говорящим |
| Тонкая настройка | Параметры Whisper, обработка звука, память модели и тайм-аут выгрузки |
| Запись | Браузер встреч, обнаружение встреч, автозапуск расшифровки, сочетание клавиш записи, разрешения в macOS |
| Диктовка | Сочетание клавиш диктовки и режим включения |
| ИИ | Задачи сводок и диктовки, подключение к платформе |
| Телефон | Передача с телефона, связывание, привязанные устройства |
| Агенты | Локальный API, навык агента, файл конфигурации |
| Расширенные | Журналы, диагностика и средства для разработчиков |

## Значения, которые стоит знать

| Группа ключей | Значение |
| --- | --- |
| `transcription.*` | Язык, промпт, диаризация, метки времени, разбиение длинных записей |
| `model.*` | Выбранная модель, отображаемые имена, устройство GPU, переключатель «только CPU», тайм-аут выгрузки |
| `transcript.*` | Формат экспорта, метки времени, говорящие, автоэкспорт |
| `recording.*` | Устройства ввода и вывода, обнаружение встреч, сочетание клавиш записи |
| `ai.*` | Платформа, базовый URL, ключ, модель, промпт и переключатели для каждой задачи |
| `general.updateChannel` | `stable`, `beta` или `dev` |
| `handoff.pairing` | Привязанные телефоны и хэши учётных данных |

Точные имена полей достаточно стабильны для редактирования, но схемой владеет приложение: меняйте значение через интерфейс настроек, когда такой вариант есть, и позволяйте приложению перезаписывать файл, а не заменяйте его целиком.
