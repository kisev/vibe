# Каналы обновлений

Приложение обновляется из одного из трёх файлов каналов на сайте, а не из «последнего выпуска» GitHub:

| Канал | Файл |
| --- | --- |
| Релиз | `https://kisev.github.io/vibe/updater/stable.json` |
| Beta | `https://kisev.github.io/vibe/updater/beta.json` |
| Dev | `https://kisev.github.io/vibe/updater/dev.json` |

Каждый файл — это `latest.json`, созданный релизной сборкой. Отсутствующий файл означает, что в ветке ничего нет: приложение сообщает «Обновлений нет», а не переключается на другой канал.

## Ветки и версии

| Канал | Тег | Ветка | Версия | Что это |
| --- | --- | --- | --- | --- |
| Релиз | `vX.Y.Z` | `main` | `X.Y.Z` | Стабильная ветка |
| Beta | `vX.Y.Z-rc.<n>` | `main` | `X.Y.Z-rc.<n>` | Кандидат в следующую стабильную версию, публикуемый как предварительный выпуск |
| Dev | `dev.<n>` | `dev` | `<config>-dev.<n>.<sha>` | Подвижная сборка ветки `dev` |

Обычный релиз отклоняется в канале beta; там принимается только `X.Y.Z-rc.<n>`. Канал без кандидата отсутствует, а не пуст.

## В приложении

- **Настройки → Общие → Обновления** содержит выбор канала, текущую версию, кнопку **Проверить обновления**, время последней проверки и результат.
- Приложение само запрашивает `updater/<channel>.json`. `404` или `410` означают, что канал никогда не публиковался; любая другая ошибка — настоящая.
- Проверка выполняется при запуске и после смены канала.

## Границы

- Обновление идёт только вперёд. Плохая сборка исправляется выпуском более новой.
- Установка Релиза или Beta, выбравшая Dev, видит «Обновлений нет»: каждая dev-сборка ниже уже установленной версии. Чтобы перейти на ветку dev, нужно один раз вручную установить dev-сборку; после этого канал Dev обновляет её дальше.
- Установка Beta переходит на финальный релиз переключением на Релиз, где `X.Y.Z` выше своих кандидатов.
