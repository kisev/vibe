# Командная строка

Исполняемый файл `vibe` — это настольное приложение. Получив любой аргумент, кроме `--hidden`, он передаёт аргументы встроенному `vibe-server` и печатает вывод этого процесса, поэтому CLI и окно используют один движок и одни модели.

Серверный исполняемый файл — `vibe-server`; рабочий каталог разработчика может вызывать его напрямую. `--help` для любой из точек входа печатает текущие флаги.

## Подкоманды

| Команда | Назначение |
| --- | --- |
| `transcribe <model> <audio>` | Транскрибировать один файл и напечатать или записать результат |
| `serve [model]` | Запустить локальный HTTP-сервер с документацией Swagger |
| `pull <url>` | Скачать модель или другой файл |
| `devices` | Перечислить устройства GPU в формате JSON |

## Параметры transcribe

| Параметр | Действие |
| --- | --- |
| `--format <txt\|markdown\|md\|json\|srt\|vtt>` | Формат вывода; по умолчанию `txt` |
| `--output <path>` | Записать в новый файл; не перезаписывает |
| `-l`, `--language <code>` | Код языка |
| `--detect-language` | Определить язык |
| `--translate` | Перевести на английский там, где модель это поддерживает |
| `--vad-model <path>` | Модель Silero VAD; требуется некоторым семействам для длинного аудио |
| `--diarize-model <path>` | Модель диаризации говорящих |
| `--prompt <text>` | Начальный промпт для моделей, которые его используют |
| `--word-timestamps` | Выводить метки времени слов там, где это поддерживается |
| `--threads <n>` | Потоки CPU |
| `--gpu-device <n>` | Индекс устройства GPU, начиная с 1; `0` или отрицательное значение — авто |
| `--cache-dir <dir>` | Сохранять завершённые фрагменты, чтобы прерванный запуск продолжился |
| `--chunk-seconds <n>` | Планируемая длина фрагмента, ограниченная окном модели |

`--enhance-audio`, `--temperature`, `--max-text-ctx`, `--max-segment-len`, `--best-of` и `--beam-size` настраивают движок; запустите `--help`, чтобы узнать их значения по умолчанию.

## Параметры serve

| Параметр | Действие |
| --- | --- |
| `--host <ip>` | Адрес привязки; по умолчанию `127.0.0.1` |
| `-p`, `--port <port>` | Порт; `0` выбирает свободный |
| `--exit-with-parent` | Остановиться вместе с родительским процессом |
| `--unload-timeout <value>` | Выгрузить простаивающую модель |
| `--cache-dir <dir>` | Папка кэша фрагментов |

**Настройки → Агенты** запускает тот же сервер из приложения и ссылается на его документацию Swagger.

## Примеры

```console
vibe transcribe model.gguf recording.wav --format srt --output recording.srt
vibe transcribe model.gguf recording.wav --language ru --vad-model ggml-silero-v6.2.0.bin
vibe devices
vibe serve --port 0
```
