# Установка Vibe

Это руководство проводит новый компьютер от загрузки до работающего окна Vibe. Предполагается настольный компьютер с подключением к интернету и без установленного Vibe. Следующий шаг — [Транскрибируйте первую запись](/vibe/docs#first-transcription).

## Загрузка установщика

Откройте [страницу загрузки](https://kisev.github.io/vibe/) и выберите сборку для этого компьютера:

| Платформа | Сборка |
| --- | --- |
| Windows | установщик `.exe` |
| macOS, Apple silicon | `aarch64.dmg` |
| macOS, Intel | `x64.dmg` |
| Linux | `.deb` или `.rpm`, x86-64 или arm64 |

Те же файлы приложены к каждому [выпуску на GitHub](https://github.com/kisev/vibe/releases). В Linux-пакете `.deb` объявлены зависимости времени выполнения, включая `ffmpeg`.

## Установка и запуск

1. Запустите установщик и следуйте его указаниям.
1. Откройте Vibe из меню приложений или запустите `vibe` в терминале.

Релизные сборки не подписаны. В macOS при первом запуске нужно щёлкнуть правой кнопкой → **Открыть** в Finder, чтобы пройти Gatekeeper; последующие запуски открываются как обычно. Windows SmartScreen может показать предупреждение по той же причине.

## Завершение настройки

При первом запуске Vibe предлагает модель по умолчанию. Примите загрузку и дождитесь её завершения. Модель хранится локально и используется при каждом следующем запуске; альтернативы перечислены в разделе [Модели](/vibe/docs#models).

Окно готово, когда видны область перетаскивания и действия **Записать** и **По ссылке**.

## Дальнейшие шаги

- [Транскрибируйте первую запись](/vibe/docs#first-transcription) опирается на эту установку.
- [Поддерживаемые форматы](/vibe/docs#formats) перечисляют, что Vibe умеет открывать и экспортировать.
- [Устранение сбоя](https://github.com/kisev/vibe/blob/main/docs/how-to/troubleshoot-a-crash.md) описывает журналы и диагностику, если окно не открывается.
