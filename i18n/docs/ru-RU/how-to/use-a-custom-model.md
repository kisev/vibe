# Импорт пользовательской модели

Vibe запускает модели GGUF через встроенный движок. Каталог в **Настройки → Модели** охватывает проверенные семейства; это руководство добавляет модель, которой в каталоге нет. Справочник о том, что поддерживает каждое семейство, — [Модели](/vibe/docs#models).

## Загрузка по URL

1. Откройте **Настройки → Модели**.
1. Вставьте прямую ссылку на модель в поле **Скачать модель** и подтвердите.
1. Дождитесь завершения загрузки; файл попадёт в папку с моделями.
1. Выберите новую модель в списке моделей.

Vibe также принимает тот же запрос как глубокую ссылку:

```text
vibe://download/?url=https://example.com/model.gguf
```

У вставленного URL нет ни размера, ни контрольной суммы, поэтому Vibe проверяет скачанные байты и заголовок GGUF/BIN, прежде чем принять файл. Записи каталога в разделе [Модели](/vibe/docs#models) содержат закреплённую ревизию, размер и SHA-256.

## Использование файла на диске

1. Поместите файл `.gguf` в папку с моделями. Путь к папке указан в **Настройки → Модели → Папка с моделями**, откуда её также можно открыть.
1. Вернитесь в **Настройки → Модели**; файл появится в списке установленных.
1. Выберите его.

Перемещайте или переименовывайте папку только через **Изменить папку для хранения моделей**, затем снова выберите модель.

## Когда модель не загружается

- Файл должен быть в формате GGUF или в устаревшем контейнере `.bin`, который принимает движок.
- Модель, которой нужен transcribe.cpp новее встроенного, есть в каталоге, но пока не может загрузиться.
- Модель с фиксированным языком отвергает другой язык; ошибка называет поддерживаемый.
