# Переключение каналов обновлений

Vibe проверяет один из трёх каналов обновлений: Релиз, Beta или Dev. Канал определяет, какие сборки предлагает приложение, и обновление всегда идёт только вперёд.

## Выбор канала

1. Откройте **Настройки → Общие → Обновления**.
1. Выберите **Релиз**, **Beta** или **Dev**.
1. Нажмите **Проверить обновления**.

В этом же разделе показаны установленная версия, время последней проверки и результат. Проверка также выполняется при запуске.

## Что содержит каждый канал

| Канал | Сборки |
| --- | --- |
| Релиз | Стабильные версии |
| Beta | Кандидаты в релиз следующей стабильной версии |
| Dev | Самые новые сборки `dev` |

Установка Релиза или Beta, выбравшая Dev, увидит **Обновлений нет**: каждая dev-сборка ниже уже установленной версии. Чтобы перейти на ветку dev, нужно один раз вручную установить dev-сборку; после этого канал Dev обновляет её дальше.

Установка Beta переходит на финальный релиз переключением на Релиз, где стабильная версия выше своих кандидатов.
