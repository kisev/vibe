# Транскрипция по ссылке

Vibe скачивает звук по ссылке на медиа с помощью yt-dlp и транскрибирует результат. Поддерживаются те сайты, которые поддерживает yt-dlp; если сайт перестал работать, обычно помогает обновлённый yt-dlp.

## Отправка ссылки

1. Откройте Vibe и выберите **По ссылке**.
1. Вставьте один URL или несколько через пробел, чтобы поставить их все в очередь.
1. Нажмите **Транскрибировать**.

При первом использовании ссылки Vibe предлагает установить yt-dlp, а при сбое сайта — обновить его. Скачанный звук временный; расшифровка сохраняется как любой другой проект.

## Чего ожидать

- Одна ссылка запускается сразу после завершения загрузки.
- Очередь обрабатывает ссылки по одной и показывает ход для каждого элемента.
- Веса, модели и расшифровка остаются локально. Сама загрузка обращается к медиахосту и к GitHub за yt-dlp.
