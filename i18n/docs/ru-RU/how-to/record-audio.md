# Запись микрофона и системного звука

Vibe записывает с выбранных устройств, а затем транскрибирует запись. Это руководство — для звонков, встреч и звука, который воспроизводится, а не сохранён в файл. Файлы рассматриваются в разделе [Поддерживаемые форматы](/vibe/docs#formats).

## Выбор устройств

1. Откройте Vibe и выберите **Записать**.
1. В разделе **Микрофон** выберите устройство ввода. Vibe запоминает устройство по имени.
1. В разделе **Динамики** выберите устройство вывода для захвата системного звука. Выберите **Пусто**, чтобы записывать только микрофон.

При записи обоих устройств они объединяются в одну дорожку с помощью ffmpeg, поэтому обе стороны звонка попадают в одну расшифровку.

## Выдача разрешений в macOS

Откройте **Настройки → Запись → Разрешения** и выдайте то, что нужно для записи:

| Разрешение | Для чего |
| --- | --- |
| Микрофон | Звук с микрофона |
| Системный звук | Звук, воспроизводимый на Mac (Запись экрана и системного звука) |

Без разрешения на системный звук macOS открывает поток обратной связи, но записывает тишину, поэтому запись непригодна.

## Запись и транскрипция

1. Нажмите **Записать**.
1. Когда звонок закончится, нажмите **Остановить**.
1. Запись откроется с выбором языка. Выберите язык или оставьте автоопределение.
1. Нажмите **Транскрибировать**.

Если в разделе **Настройки → Запись** включено **Автоматически расшифровывать записи**, последний шаг запускается сам.
