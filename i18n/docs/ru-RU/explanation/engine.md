# Движок и выбор GPU

Vibe отделяет настольную оболочку от движка транскрипции. Оболочка — приложение Tauri на Rust и React; движок — `vibe-server`, процесс на Rust, вызывающий библиотеку C++ transcribe.cpp поверх ggml.

## Почему движок — отдельный процесс

Сервер отвечает за загрузку моделей и тяжёлые вычисления. Вынесение его из настольного процесса означает:

- окно можно перезапустить, не загружая многогигабайтную модель заново;
- один и тот же бинарный файл обслуживает приложение, CLI и локальный HTTP API;
- сбой в движке не утягивает за собой окно;
- движок можно обновлять по собственному графику, закреплённому сборкой приложения.

Настольное приложение общается с сервером по локальному HTTP. Ничто на этом пути не покидает машину; сетевую поверхность описывает раздел [Приватность и работа офлайн](/vibe/docs#privacy).

## Один движок, много семейств моделей

Каждое поддерживаемое семейство работает через одну сборку ggml: Whisper, Parakeet, Nemotron, Canary, Qwen3-ASR, Voxtral и GigaAM. Silero VAD и диаризация Nemotron-3 тоже работают на этом стеке. Один движок обеспечивает одинаковую работу с памятью, квантование и диспетчеризацию GPU для всех моделей.

Компромисс — привязка версий: модель, чей GGUF требует transcribe.cpp новее встроенной сборки, есть в разделе [Модели](/vibe/docs#models), но не загрузится, пока движок не обновится. Эта привязка намеренная, потому что обновления движка — события паритета, а не фоновые обновления зависимостей.

## Бэкенды GPU

ggml выбирает бэкенд для машины, на которой работает:

| Платформа | Бэкенд |
| --- | --- |
| macOS | Metal |
| Windows | Vulkan |
| Linux | Vulkan |

Машина без пригодного GPU работает на CPU. В разделе **Настройки → Модели** есть **Расшифровывать на CPU** и, в Windows и Linux, выбор устройства GPU. Если загрузка на GPU не удаётся, приложение повторяет попытку на CPU и сообщает об этом.

GPU важнее всего для больших моделей и длинных файлов. Небольшие модели на современном CPU могут работать достаточно быстро, а путь через CPU — запасной вариант, когда нет драйвера или загрузчика Vulkan.
