# Přepis z odkazu

Vibe stáhne zvuk za mediální URL pomocí yt-dlp a výsledek přepíše. Podporované jsou stránky, které podporuje yt-dlp; když nějaká stránka přestane fungovat, obvykle to vyřeší aktualizovaný yt-dlp.

## Odeslání odkazu

1. Otevřete Vibe a zvolte **Z odkazu**.
1. Vložte jednu URL, nebo vložte několik URL oddělených bílými znaky a všechny se zařadí do fronty.
1. Stiskněte **Přepsat**.

Vibe se při prvním použití odkazu zeptá na instalaci yt-dlp a při selhání stránky na jeho aktualizaci. Stažený zvuk je dočasný; přepis se uloží jako každý jiný projekt.

## Co očekávat

- Jeden odkaz se spustí hned po dokončení stahování.
- Fronta zpracovává odkazy jeden po druhém a u každé položky zobrazuje průběh.
- Váhy, modely a přepis zůstávají lokálně. Samotné stahování kontaktuje hostitele média a GitHub kvůli yt-dlp.
