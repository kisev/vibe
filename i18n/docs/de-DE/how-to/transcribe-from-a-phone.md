# Vom Telefon transkribieren

Vibe kann auf einem Telefon aufnehmen und auf diesem Computer transkribieren. Das Telefon öffnet nach dem Scannen eines Codes eine kleine Web-App; aus einem App-Store wird nichts installiert. Lassen Sie Vibe während der Aufnahme geöffnet.

## Übergabe aktivieren

1. Öffnen Sie **Einstellungen → Telefon**.
1. Aktivieren Sie **Aufnahmen vom Telefon zulassen**.
1. Wählen Sie **Telefon koppeln** und dann **Code anzeigen**.

## Telefon koppeln

1. Richten Sie die Telefonkamera auf den QR-Code.
1. Öffnen Sie die angebotene Seite und lassen Sie sie geöffnet.
1. Das Gerät erscheint unter **Gekoppelte Geräte**, sobald die Kopplung abgeschlossen ist.

Die Kopplung übersteht Neustarts der App und des Telefonbrowsers. Jedes Browserprofil ist ein eigenes Gerät.

## Aufnehmen und transkribieren

1. Nehmen Sie auf der Telefonseite auf.
1. Das Audio läuft Ende-zu-Ende-verschlüsselt über den Relay; dieser Computer empfängt es, transkribiert es und schickt das Transkript zurück.
1. Das Transkript landet außerdem unter Zuletzt verwendet auf dem Computer.

## Geräte verwalten

- **Widerrufen** sperrt dieses Gerät und unterbricht eine aktive Übergabe.
- **Neuen Code erstellen** ersetzt die Einladung. Bereits gekoppelte Telefone behalten den Zugriff.
- **Alle widerrufen** zwingt jedes Telefon, einen neuen Code zu scannen.
