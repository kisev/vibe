# 対応フォーマット

Vibe は音声・動画ファイルを受け付け、文字起こしをいくつかのテキスト形式でエクスポートします。デスクトップアプリは文字起こしの前に ffmpeg でメディアを正規化します。Linux ではシステムの `ffmpeg` が必要で、macOS と Windows のバンドルにはそれぞれ同梱されています。

## 入力

| 種類 | 拡張子 |
| --- | --- |
| 音声 | `mp3`, `wav`, `aac`, `flac`, `oga`, `ogg`, `opus`, `m4a`, `m4b`, `wma` |
| 動画 | `mp4`, `mkv`, `avi`, `mov`, `wmv`, `webm`, `mxf` |

この一覧にないコンテナでも、ffmpeg がデコードできれば動作することがあります。アプリが受け付けない場合は、先に変換してください。

## デスクトップでのエクスポート

文字起こしのエクスポートダイアログを開き、次のいずれかを選びます:

| フォーマット | 内容 |
| --- | --- |
| TXT | 書式なしのプレーンテキスト |
| Markdown | 見出しと書式付きの Markdown |
| SRT | 番号付きタイムスタンプを含む字幕 |
| VTT | タイムスタンプを含むウェブ字幕 |
| HTML | スタイル付きのウェブページ |
| JSON | 構造化された文字起こしと時間データ |
| CSV | 表計算ソフトですぐ使える文字起こしデータ |
| DOCX | 書式設定された Word 文書 |
| PDF | 印刷可能な文書 |

エクスポートオプションでは、フォーマットが対応している場合にタイムスタンプと話者ラベルも切り替えられます。自動エクスポートは、これらの形式のいずれかを録音の隣、プロジェクトフォルダー、または選択したフォルダに書き出せます。

## CLI 出力

`vibe-server transcribe` は `txt`（デフォルト）、`markdown`（別名 `md`）、`json`、`srt`、`vtt` を書き出します。`--output` は新しいファイルを書き込み、既存のパスへの上書きを拒否します。[コマンドライン](/vibe/docs#cli)を参照してください。
