# 設定と構成

設定はアプリの構成ディレクトリにある `app_config.json` にあります。このファイルは読んで編集することを想定しています。Vibe はファイルを監視し、外部からの変更を再起動なしで適用します。**設定 → エージェント → 設定ファイル** から開けます。

## 設定ファイルの場所

| プラットフォーム | ディレクトリ |
| --- | --- |
| macOS | `~/Library/Application Support/github.com.thewh1teagle.vibe` |
| Windows | `%appdata%\github.com.thewh1teagle.vibe` |
| Linux | `~/.config/github.com.thewh1teagle.vibe` |

ディレクトリは上流の識別子を保持しているため、名前は以前のビルドから変わっていません。

## 設定セクション

| セクション | 内容 |
| --- | --- |
| 一般 | 表示言語、テーマ、アップデート、閉じても通知領域で実行を続ける、ログイン時に自動起動、コンピューターをスリープさせない |
| プライバシー | プロジェクトを保存するかどうか、およびプライバシーポリシー |
| 文字起こし | 言語、自動エクスポート、完了時の音とフォーカス、プロジェクトフォルダー |
| モデル | CPU/GPU の選択、GPU デバイス、モデルカタログ、話者分離モデル |
| 詳細調整 | Whisper オプション、音声処理、モデルメモリとアンロードのタイムアウト |
| 録音 | 会議ブラウザ、会議の検出、自動文字起こし、録音ショートカット、macOS の権限 |
| 音声入力 | 音声入力のショートカットと動作モード |
| AI | 要約と音声入力タスク、プラットフォーム接続 |
| スマートフォン | スマートフォン連携、ペアリング、ペアリング済みデバイス |
| エージェント | ローカル API、エージェントスキル、設定ファイル |
| 詳細設定 | ログ、診断、開発者向けコントロール |

## 知っておくべき値

| キーグループ | 意味 |
| --- | --- |
| `transcription.*` | 言語、プロンプト、話者分離、タイムスタンプ、長時間録音のチャンク分割 |
| `model.*` | 選択中のモデル、表示名、GPU デバイス、CPU のみの切り替え、アンロードのタイムアウト |
| `transcript.*` | エクスポート形式、タイムスタンプ、話者、自動エクスポート |
| `recording.*` | 入力デバイスと出力デバイス、会議の検出、録音ショートカット |
| `ai.*` | プラットフォーム、ベース URL、キー、モデル、タスクごとのプロンプトとスイッチ |
| `general.updateChannel` | `stable`、`beta`、`dev` |
| `handoff.pairing` | ペアリング済みのスマートフォンデバイスと認証情報ハッシュ |

フィールド名は編集できる程度に安定していますが、スキーマはアプリが所有します。設定 UI がある値は UI から変更し、ファイル全体を置き換えるのではなく、アプリにファイルを書き換えさせてください。
