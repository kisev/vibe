# アップデートチャンネルを切り替える

Vibe はリリース、ベータ、開発の 3 つのアップデートチャンネルのうち 1 つを確認します。チャンネルはアプリが提供するビルドを決め、常に前方向にのみ進みます。

## チャンネルを選ぶ

1. **設定 → 一般 → アップデート** を開きます。
1. **リリース**、**ベータ**、**開発** のいずれかを選びます。
1. **アップデートを確認** を押します。

同じセクションに、インストール済みのバージョン、最終確認時刻、結果が表示されます。確認は起動時にも実行されます。

## 各チャンネルが提供するもの

| チャンネル | ビルド |
| --- | --- |
| リリース | 安定版 |
| ベータ | 次の安定版のリリース候補 |
| 開発 | 最新の `dev` ビルド |

開発を選んだリリースまたはベータのインストールでは **最新です** と表示されます。すべての開発ビルドは、すでに実行中のバージョンより下に位置するためです。開発ラインに移るには開発ビルドを 1 回手動でインストールする必要があり、その後は開発チャンネルが前方向に更新します。

ベータのインストールはリリースに切り替えることで最終リリースに移ります。安定版のバージョンはその候補より上に位置するためです。
