# 文字起こしを要約する

Vibe は完成した文字起こしを要約、メモ、または翻訳に変えられます。リクエストは設定した AI プラットフォームに送られます: ローカルの Ollama モデル、Claude、または OpenAI 互換のエンドポイントです。接続がどこに保存されるかは[設定と構成](/vibe/docs#settings)に一覧されています。

## ローカルの Ollama モデルを使う

1. [Ollama](https://ollama.com) をインストールし、モデルを取得します。例えば `ollama pull llama3.1` です。
1. **設定 → AI** を開きます。
1. **プラットフォーム** を **Ollama** に設定します。デフォルトの URL は `http://localhost:11434` です。
1. モデル名を選びます。
1. **要約** をオンにし、必要に応じて **新しい文字起こしを自動的に要約** もオンにします。

Ollama はこのコンピューター上で動作するため、文字起こしはローカルに留まります。

## Claude または OpenAI 互換のエンドポイントを使う

1. **設定 → AI** を開き、プラットフォームを選びます。
1. API キーを貼り付け、エンドポイントがデフォルトでない場合はベース URL を変更します。
1. モデルを選びます。
1. **要約** をオンにします。

デフォルト以外のエンドポイントでは、ベース URL とキーが、要約と音声入力の両方でアプリが使う接続になります。

## 要約する

1. 文字起こしを完了します。
1. 文字起こしビューで要約アクションを開きます。
1. プリセットを選び、必要ならプロンプトを編集します。
1. 実行します。結果はプロジェクトとともに保存され、文字起こしの隣にエクスポートできます。

**新しい文字起こしを自動的に要約** が有効な場合、文字起こしが完了するとすぐに要約が実行されます。
