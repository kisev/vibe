# 会議ブラウザを使う

Vibe は通話を独自の Chromium ベースのウィンドウでホストできます。アプリのバー（アドレス、戻る、進む、再読み込み、システムのブラウザで開く、閉じる、**この通話を録音**）が上部にあり、ページが同じウィンドウの残りを埋めます。別のバーウィンドウはありません。URL スキームと許可リストについては[会議ブラウザのリファレンス](../reference/meeting-browser.md)を、この仕組みがこうなっている理由については[解説](../explanation/meeting-browser.md)を参照してください。

## Vibe で通話を開く

次のいずれかの方法を使います:

- 別のアプリまたはシステムから: **設定 → 録音** の **Vibe で会議リンクを開く** をオンにすると、Zoom、Teams、Webex のリンクが登録されます（Windows と Linux、macOS は対象外）。アプリはマッピングされた URL を検証し、ホストの読み込みが許可されている場合はブラウザウィンドウで、そうでない場合はシステムのブラウザで開きます。
- Vibe 内から: ホームページの **会議ブラウザ** ソース、または **設定 → 録音 → Vibe で開く** を使い、リンクを貼り付けて **Vibe で開く** を押します。
- リンクのホストは許可リストに含まれている必要があります。許可リスト外のトップレベルナビゲーションとクロスオリジンリソースは拒否されます。バーの録音コントロールは、許可されたすべてのページに表示されます。

Chrome、Edge、Firefox で https リンクをクリックしても、そのブラウザが開きます。Vibe はデフォルトブラウザとして登録されません。

## 通話を録音する

1. Vibe で会議を開きます。
1. 通話の前または通話中に、ウィンドウのバーで **この通話を録音** を押します。
1. バーまたはメインウィンドウから停止します。

録音は手動です。会議ウィンドウが自動的に録音を開始することはありません。レコーダーは設定済みのマイクと、有効な場合はシステムオーディオのループバックを取り込むため、通話の両側が録音されます。

バーにあるマイクとスピーカーの選択は、メインウィンドウが使うのと同じデバイスを変更するため、通話から離れずにルーティングできます。録音の実行中は無効になり、取り込み中のデバイス名を表示します。その実行で取り込まれないソースには **なし** と表示されます。

録音中にウィンドウを閉じると、停止するかバックグラウンドで録音を続けるかを確認されます。

## 使用するサイトを許可する

**設定 → 録音 → 許可されたドメイン** はブラウザの許可リストです。初期状態では空です。必要なドメインをそれぞれ追加すると、そのサブドメインも https 経由で含まれます。

読み込めるのは一覧にあるドメインのみです。別のホストへのリンクは拒否され、許可されたページが一覧にないオリジンから取得するスクリプト、フォント、画像も同様に拒否されます。拒否されたホストは **ブロック中** に **許可** 操作付きで表示され、許可するとドメインが追加されてページが再読み込みされます。バーは、ナビゲーションを拒否するときにも同じ提案を表示します。

厳格な一覧は、アセットを CDN から取得するページを、その CDN が許可されるまで壊す可能性があります。これは意図されたトレードオフであり、ブロック中の一覧によって修正は 1 回のクリックで済みます。

## システムのブラウザに切り替える

サービスが埋め込み webview での動作を拒否する場合は、バーの **システムのブラウザで開く** を使用します。システムのブラウザは、DRM の多いサイトや WebRTC に厳しいサイト向けの、サポートされるフォールバックです。

macOS では、埋め込みブラウザにウィンドウ内のバーがありません。ページはページのみのウィンドウで開き、録音はメインウィンドウから引き続き利用でき、通話全体についてはシステムのブラウザがフォールバックです。
