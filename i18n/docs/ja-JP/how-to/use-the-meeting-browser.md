# 会議ブラウザを使う

Vibe は通話を独自のウィンドウでホストでき、常に最前面のバーには主な操作として **この通話を録音** が表示されます。ウィンドウはプラットフォームの webview を使用します。分離と制限については[会議ブラウザがこの仕組みである理由](/vibe/docs#meeting-browser)で説明しています。

## Vibe で通話を開く

次のいずれかの方法を使います:

- **設定 → 録音 → Vibe で開く** を開き、リンクを貼り付けて開きます。
- 別のアプリ、スクリプト、ショートカットから `vibe://open/?url=https://…` を呼び出します。Vibe は整形式の https URL のみを受け付け、それ以外はダイアログで拒否します。
- **設定 → 録音** の **Vibe で会議リンクを開く** をオンにすると、Zoom、Teams、Webex のリンクが登録されます。これは Windows と Linux で利用でき、macOS では利用できません。

Chrome、Edge、Firefox で https リンクをクリックしても、そのブラウザが開きます。Vibe はデフォルトブラウザとして登録されません。

## 録音バーを表示する

**設定 → 録音 → 会議ホスト** には、会議バーを表示するホストが一覧されています。デフォルトは `telemost.yandex.ru` と `stream.wb.ru` です。

- ホストを追加すると、そのリンクが録音可能なセッションになります。
- ホストを削除するとバーが表示されなくなります。そのリンクは引き続きブラウザウィンドウで開きます。

照合は https 上のホスト名で行われるため、`sub.telemost.yandex.ru` は `telemost.yandex.ru` の項目に一致しますが、`http` URL は一致しません。一覧は便利なフィルターであり、セキュリティ境界ではありません。すべての https リンクがウィンドウで開きますが、バーが表示されるのは一覧にあるホストだけです。

## 通話を録音する

1. Vibe で会議を開きます。
1. 通話の前または通話中に **この通話を録音** を押します。
1. バーまたはメインウィンドウから停止します。

録音は手動です。会議ウィンドウが自動的に録音を開始することはありません。レコーダーは設定済みのマイクと、有効な場合はシステムオーディオのループバックを取り込むため、通話の両側が録音されます。

録音中にウィンドウを閉じると、停止するかバックグラウンドで録音を続けるかを確認されます。

## システムのブラウザに切り替える

サービスが埋め込み webview での動作を拒否する場合は、バーの **システムのブラウザで開く** を使用します。DRM の多いサイトや WebRTC に厳しいサイト向けの、サポートされるフォールバックです。
