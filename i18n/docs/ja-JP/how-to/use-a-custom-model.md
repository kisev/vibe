# カスタムモデルをインポートする

Vibe は GGUF モデルを同梱エンジンで実行します。**設定 → モデル** のカタログにはテスト済みのファミリーが載っています。このガイドでは、カタログにないモデルを 1 つ追加します。各ファミリーが何に対応するかのリファレンスは[モデル](/vibe/docs#models)です。

## URL からダウンロードする

1. **設定 → モデル** を開きます。
1. **モデルをダウンロード** に直接のモデルリンクを貼り付けて確定します。
1. ダウンロードが終わるまで待ちます。ファイルはモデルフォルダに保存されます。
1. モデル一覧で新しいモデルを選択します。

Vibe は同じリクエストをディープリンクとしても受け付けます:

```text
vibe://download/?url=https://example.com/model.gguf
```

貼り付けた URL にはサイズもチェックサムもないため、Vibe はダウンロードしたバイトと GGUF/BIN ヘッダーを確認してからファイルを受け入れます。[モデル](/vibe/docs#models)のカタログ項目には、固定されたリビジョン、サイズ、SHA-256 があります。

## ディスク上のファイルを使う

1. `.gguf` ファイルをモデルフォルダに置きます。フォルダのパスは **設定 → モデル → モデルフォルダ** にあり、そこから開くこともできます。
1. **設定 → モデル** に戻ります。ファイルがインストール済みの一覧に表示されます。
1. それを選択します。

フォルダの移動や名前変更は **モデルフォルダを変更** からのみ行い、その後でモデルを選択し直してください。

## モデルが読み込まれない場合

- ファイルは GGUF か、エンジンが受け付ける従来の `.bin` コンテナである必要があります。
- 同梱のものより新しい transcribe.cpp を必要とするモデルは、カタログには載っていますが、まだ読み込めません。
- 固定言語のモデルは別の言語を拒否します。エラーには対応している言語名が示されます。
