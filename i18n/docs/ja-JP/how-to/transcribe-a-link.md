# リンクから文字起こしする

Vibe はメディア URL の背後にある音声を yt-dlp でダウンロードし、その結果を文字起こしします。対応サイトは yt-dlp が対応しているサイトです。サイトが動かなくなった場合、通常は yt-dlp をアップデートすると直ります。

## リンクを送る

1. Vibe を開き、**リンクから** を選びます。
1. URL を 1 つ貼り付けるか、空白で区切って複数貼り付けてすべてをキューに入れます。
1. **文字起こし** を押します。

Vibe は初めてリンクを使うときに yt-dlp のインストールを求め、サイトで失敗したときはアップデートを求めます。ダウンロードした音声は一時的なものです。文字起こしは他のプロジェクトと同様に保存されます。

## 期待できること

- 1 つのリンクはダウンロードが終わり次第開始されます。
- キューは 1 つずつリンクを処理し、項目ごとに進行状況を表示します。
- 重み、モデル、文字起こしはローカルに留まります。ダウンロード自体はメディアのホストと、yt-dlp のために GitHub に接続します。
