## Decisions

Ten open findings, grouped (the ffmpeg bullet covers three: the two checksums and the duplicated
URL).

- **ffmpeg checksums** (`fetch_ffmpeg.py`, `package_server_release.sh`): pin an ffmpeg version and a
  SHA-256 per target before adding verification. gyan.dev publishes `<url>.sha256`; the osxexperts
  archives have no checksums, so their hashes must be committed. A shared pin file would also fix
  the duplicated URLs.
- **ggml archive integrity** (`ggml_libs.sh`): the release body's tree id cannot be compared with
  the local tree — the archives live in the upstream repository, and the local `server/libs` tree
  hash differs by construction. The workable alternative is a committed SHA-256 manifest per
  platform, generated by `upload`.
- **Public suffixes** (`browser_policy.rs`): the dot rule rejects `com` but still accepts `co.uk`
  and `github.io`. Closing that needs the public suffix list; `publicsuffix` is already in the lock
  transitively and would become a direct dependency.
- **Blocked hosts under trusted-site** (`meeting-browser.tsx`): refused navigations are recorded in
  both modes, but the settings list is shown only for strict mode; hiding it is asserted by tests.
  Showing it is a small code change and a product call.
- **Diarization default** (`preference.tsx`): a fresh install has `diarizeEnabled` on with no model,
  so the toggle reads on while transcription runs without speakers. Either default it off until a
  model exists or resolve the model before the first transcription.
- **Recording start failures** (chrome): the gate now sees Rust's recording state, but a refused
  start still reports only in the main window. Surfacing it in the chrome needs a message and a
  payload field.
- **Language selector across breakpoints** (`Nav.tsx`): the hidden instance can stay open when the
  viewport crosses `sm`. A correct fix needs a `matchMedia('(min-width: 640px)')` listener.
- **Roadmap translation coverage**: 12 of 34 active changes lack roadmap translations; the English
  fallback is documented as intentional. A `translate` run closes the gap.
